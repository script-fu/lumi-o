AppImage — однофайловий пакет Linux-програми. Завантажуєте один файл, позначаєте його виконуваним і запускаєте без системного встановлення.

Офіційний сайт AppImage: https://appimage.org/

AppImage дає портативну версію Lumi, яка працює без встановлення чи змін у системі. Це зручно для художників, які хочуть одразу користуватися програмою, не керуючи залежностями, не компілюючи вихідний код і не налаштовуючи середовище розробки.

Як самодостатній виконуваний файл AppImage можна зберігати будь-де в системі. Це полегшує тестування нових випусків, збереження кількох версій або перенесення програми між машинами.

У процесі розробки Lumi AppImage слугує портативною тестовою збіркою, яка тісно відповідає результатам безперервної інтеграції. Це дає надійне тестування в узгодженому середовищі, тоді як локальні збірки з вихідного коду залишаються зосередженими на розробці.

Примітка: CI збирає AppImage з інтегрованих джерел залежностей у репозиторії Lumi (BABL/GEGL/GTK3), тож стек залежностей узгоджується з локальним робочим процесом `lumi-build-script.sh`.

## Release і AppImage для розробки

- **Release AppImage**: ще недоступний (Lumi ще не випущено).
- **AppImage для розробки (артефакт CI)**: автоматично створюється з поточних комітів розробки для тестування.

Цей посібник переважно описує робочий процес **AppImage для розробки**.

Поточна сторінка артефактів:

https://gitlab.gnome.org/pixelmixer/lumi-dev/-/artifacts

## Основи завантаження AppImage з CI

CI створює zip-архіви з артефактами (наприклад, `lumi-appimage*.zip`).

Базовий ручний процес:

1. Завантажте останній zip-архів артефакту CI.
2. Розпакуйте його.
3. Запустіть файл `Lumi*.AppImage` з архіву.

Скрипти нижче — необов’язкові помічники, які автоматизують ці кроки.

```bash
cd ~/code/lumi-dev/build/lumi/scripts

# Розпакувати останній завантажений zip CI з ~/Downloads
bash lumi-appimage-unpack-zip.sh

# Запустити AppImage з виводом у термінал
bash lumi-appimage-launch.sh
```

## Додаткові допоміжні скрипти

- `lumi-appimage-unpack-zip.sh`
  - знаходить останній `lumi-appimage*.zip` у `~/Downloads`
  - встановлює AppImage у `~/AppImage/Lumi/Lumi_CI.AppImage`
  - встановлює ресурси робочого столу в `~/.local/share/applications/lumi.desktop`

- `lumi-appimage-launch.sh`
  - запускає AppImage в терміналі
  - вмикає вивід під час виконання (`APPIMAGE_DEBUG=1`)

## Загальні примітки

- Якщо запускаєте AppImage вручну (без допоміжних скриптів), спочатку зробіть його виконуваним:

```bash
chmod +x ~/AppImage/Lumi/Lumi_CI.AppImage
```

`lumi-appimage-unpack-zip.sh` уже автоматично встановлює дозволи на виконання.

- Якщо Lumi вже запущено з іншої збірки, закрийте її перед запуском AppImage.

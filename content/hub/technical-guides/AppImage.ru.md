AppImage — это однофайловый пакет приложения для Linux. Вы загружаете один файл, делаете его исполняемым и запускаете без установки ПО в систему.

Официальный сайт AppImage: https://appimage.org/

AppImage предоставляет портативную версию Lumi, которая работает без установки и без изменений системы. Он идеально подходит для художников, которые хотят сразу использовать программу, не управляя зависимостями, не компилируя исходный код и не настраивая среду разработки.

Как автономный исполняемый файл AppImage можно хранить где угодно в системе. Это упрощает тестирование новых релизов, хранение нескольких версий и перенос программы между компьютерами.

В процессе разработки Lumi AppImage служит портативной тестовой сборкой, которая близко соответствует результатам непрерывной интеграции. Это обеспечивает надёжное тестирование в согласованной среде, сохраняя локальные сборки исходников сфокусированными на разработке.

Примечание: CI собирает AppImage с использованием интегрированных в репозиторий источников зависимостей Lumi (BABL/GEGL/GTK3), поэтому стек зависимостей согласован с локальным рабочим процессом `lumi-build-script.sh`.

## Release и AppImage для разработки

- **Release AppImage**: пока недоступен (Lumi ещё не выпущен).
- **AppImage для разработки (артефакт CI)**: автоматически создаётся из текущих коммитов разработки для тестирования.

В этом руководстве в основном рассматривается рабочий процесс **AppImage для разработки**.

Текущая страница артефактов:

https://gitlab.gnome.org/pixelmixer/lumi-dev/-/artifacts

## Основы загрузки AppImage из CI

CI создаёт zip-файлы артефактов (например, `lumi-appimage*.zip`).

Базовый ручной порядок действий:

1. Загрузите последний zip-архив артефактов CI.
2. Распакуйте его.
3. Запустите прилагаемый файл `Lumi*.AppImage`.

Приведённые ниже скрипты — необязательные помощники, автоматизирующие эти шаги.

```bash
cd ~/code/lumi-dev/build/lumi/scripts

# Unpack latest downloaded CI zip from ~/Downloads
bash lumi-appimage-unpack-zip.sh

# Launch AppImage with terminal output
bash lumi-appimage-launch.sh
```

## Дополнительные вспомогательные скрипты

- `lumi-appimage-unpack-zip.sh`
  - находит последний `lumi-appimage*.zip` в `~/Downloads`
  - устанавливает AppImage в `~/AppImage/Lumi/Lumi_CI.AppImage`
  - устанавливает ресурсы рабочего стола в `~/.local/share/applications/lumi.desktop`

- `lumi-appimage-launch.sh`
  - запускает AppImage в терминале
  - включает вывод во время выполнения (`APPIMAGE_DEBUG=1`)

## Общие примечания

- Если вы запускаете AppImage вручную (без вспомогательных скриптов), сначала сделайте его исполняемым:

```bash
chmod +x ~/AppImage/Lumi/Lumi_CI.AppImage
```

`lumi-appimage-unpack-zip.sh` уже автоматически устанавливает права на выполнение.

- Если Lumi уже запущен из другой сборки, закройте его перед запуском AppImage.

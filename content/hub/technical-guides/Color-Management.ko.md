Lumi-o는 바로 사용할 수 있도록 구성되어 있습니다. **16비트 이상의 정밀도**로 이미지를 작업하는 한, 소프트웨어는 기본 번들 소프트 프루프(CMYK)와 내장 sRGB 프로필을 사용하도록 이미 설정되어 있어 추가 구성 없이 동작합니다.

더 깊은 제어가 필요한 경우, 이 가이드는 Lumi의 핵심 색상 관리 모델, 이미지 프로필과 소프트 프루프 프로필의 차이, 컨트롤 위치, 기본 프로필 번들 방식을 설명합니다.

## 요약

Lumi는 세 가지 프로필 역할을 사용합니다:

1. **이미지 작업 프로필**
   - 이미지 RGB 또는 그레이스케일 숫자의 의미를 정의합니다.
   - 할당/변환 작업에 사용됩니다.
   - 예: 내장 sRGB, Adobe RGB.

2. **디스플레이 프로필**
   - 모니터를 설명합니다.
   - 화면에 이미지를 올바르게 표시하는 데 사용됩니다.
   - 보통 시스템이 제공하거나 기본 설정에서 선택합니다.

3. **소프트 프루프 프로필**
   - 다른 출력 장치나 인쇄 조건을 시뮬레이션합니다.
   - 이미지 픽셀 값을 **재정의하지 않습니다**.
   - 예: `CoatedFOGRA39` 같은 CMYK 인쇄 프로필.

## 이미지 프로필과 소프트 프루프 프로필

### 이미지 프로필

이미지가 실제로 어떤 색 공간에 있는지 Lumi에 알리고 싶을 때 사용합니다.

두 가지 일반적인 작업:

- **프로필 할당**
  - 이미지에 붙은 프로필 레이블을 변경합니다.
  - 픽셀 값을 **변환하지 않습니다**.
  - 픽셀 숫자가 이미 해당 프로필 색 공간에 있을 때만 사용합니다.

- **프로필로 변환**
  - 현재 이미지 프로필에서 새 프로필로 픽셀 값을 변환합니다.
  - 이미지를 실제로 다른 작업 색 공간으로 옮기고 싶을 때 사용합니다.

**메뉴 위치:**
- 이미지 > 색상 관리 > 색상 프로필 할당...
- 이미지 > 색상 관리 > 색상 프로필로 변환...

### 소프트 프루프 프로필

대상 장치나 인쇄 조건에서의 재현을 미리 보고 싶을 때 사용합니다.

소프트 프루프:
- 이미지 작업 색 공간은 그대로 유지
- 미리보기 파이프라인 변경
- 색역 밖 색상 표시 가능
- 이미지 데이터 재할당이 아닌 미리보기용

**메뉴 위치:**
- 이미지 > 색상 관리 > 소프트 프루프 설정 > 소프트 프루프 프로필 선택...
- 이미지 > 색상 관리 > 소프트 프루프 설정 > 렌더링 의도
- 이미지 > 색상 관리 > 소프트 프루프 설정 > 블랙 포인트 보정
- 보기 > 색상 관리 > 소프트 프루프 미리보기 사용
- 보기 > 색상 관리 > 색역 밖 색상 표시

## 소프트 프루프 미리보기 보기

소프트 프루프를 전환하는 주요 진입점은 두 가지입니다.

### 1. 보기 메뉴

다음 사용:
- 보기 > 색상 관리 > 소프트 프루프 미리보기 사용

현재 디스플레이에 대한 미리보기 시뮬레이션을 켜거나 끕니다.

### 2. 상태 표시줄 토글

Lumi는 하단 상태 표시줄에서 직접 소프트 프루프를 제공합니다.

- **왼쪽 클릭**(토글): 프루프 색상 사용/해제
- **오른쪽 클릭**: 조정할 수 있는 소프트 프루프 팝오버 열기:
  - 현재 프로필
  - 프로필 선택기
  - 렌더링 의도
  - 블랙 포인트 보정
  - 색역 밖 표시

{{< callout type="warning" >}}
**정밀도에 대한 중요 참고**
소프트 프루프 미리보기는 **16비트 및 32비트** 이미지에서만 사용할 수 있습니다.
**8비트** 이미지에서는 토글이 비활성화되며, Lumi는 색상을 정확히 미리보기 전에 먼저 더 높은 비트 깊이로 정밀도를 변환하라고 안내합니다.
{{< /callout >}}

## 기본 설정 및 기본값

전역 기본값 위치:
- 편집 > 기본 설정 > 색상 관리

관련 섹션:
- **수동 모니터 프로필**
- **선호 RGB 프로필**
- **선호 그레이스케일 프로필**
- **소프트 프루프**

### 현재 Lumi 기본값

#### 작업 색 공간

공유 데이터 폴더에서 제공되는 번들 작업 색 공간 ICC:
- `AdobeRGB1998.icc`
- `AppleRGB.icc`

표준 sRGB 작업을 위해 Lumi는 **내장 sRGB 작업 프로필**도 내부적으로 제공합니다.

#### 소프트 프루프 기본값

현재 설치된 번들 소프트 프루프 프로필:
- `CoatedFOGRA39.icc`
- `USWebCoatedSWOP.icc`
- `JapanColor2001Coated.icc`

사용 가능한 경우 `CoatedFOGRA39.icc`가 기본 번들 소프트 프루프/CMYK 참조 프로필로 사용됩니다.

## 실용적인 워크플로

### 그리기 및 일반 화면 작업

- 이미지를 내장 sRGB 또는 다른 유효한 RGB 작업 색 공간에 유지
- 가능하면 Lumi가 시스템 모니터 프로필 사용

### 인쇄 미리보기

- 이미지를 표준 RGB 작업 색 공간에 유지
- 대상 인쇄 조건에 맞는 소프트 프루프 프로필 선택(예: FOGRA39)
- 소프트 프루프 미리보기 사용
- 필요하면 색역 경고를 사용해 클리핑된 렌더링 의도 확인

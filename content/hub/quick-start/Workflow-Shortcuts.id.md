Lumi-o dibuat untuk alur kerja berbasis pintasan. Setelah Anda membangun memori otot untuk perintah ini, Anda dapat menavigasi kanvas dan alat dengan jauh lebih cepat.

## Kontrol kanvas penting

| Aksi | Pintasan |
| :--- | :--- |
| **Sesuaikan Ukuran Kuas** | `Alt` + Klik Kanan & Tarik |
| **Siklus Pemilihan Lapisan** | `Alt` + Arahkan kursor di atas kanvas |



## Konfigurasi & penyimpanan

Untuk melihat atau memetakan ulang pintasan yang ada, buka:

**Edit → Pintasan Keyboard**

> **Catatan tentang penyimpanan:** Konfigurasi pintasan khusus Anda disimpan ke file konfigurasi hanya saat **File → Keluar** yang benar. Pastikan Anda menutup aplikasi melalui menu setelah melakukan perubahan signifikan agar pengaturan tetap tersimpan.

Lumi-o dibuat untuk alur kerja berbasis pintasan. Setelah Anda membangun memori otot untuk perintah ini, Anda dapat menavigasi kanvas dan alat dengan jauh lebih cepat.

## Kontrol kanvas penting

| Aksi | Pintasan |
| :--- | :--- |
| **Sesuaikan Ukuran Kuas** | `Alt` + Klik Kanan & Tarik |
| **Siklus Pemilihan Lapisan** | `Alt` + Arahkan kursor di atas kanvas |



{{< callout type="info" >}}
**Tip: Konflik tombol Alt di Linux**

Jika `Alt` + klik kanan dan seret tidak mengubah ukuran kuas di Lumi, desktop menggunakan Alt untuk manajemen jendela.

1. Cari **Jendela** di menu sistem.
2. Jendela → Tingkah laku → Tombol khusus untuk menggerakkan dan mengubah ukuran jendela → **Dinonaktifkan**

Setelah perubahan ini, `Alt` + klik kanan dan seret seharusnya berfungsi di Lumi untuk mengubah ukuran alat.
{{< /callout >}}

## Bergerak di kanvas

Geser dan zoom tetap memakai alat yang sedang dipilih.

| Aksi | Pintasan |
| :--- | :--- |
| **Geser** | Klik tengah dan seret |
| **Geser** | Tahan `Space` dan seret |
| **Zoom** | `Ctrl` + klik tengah dan seret |

`Space` menggeser tampilan secara bawaan.

## Putar tampilan

Putar kanvas agar goresan yang sudah terlatih keluar ke arah yang nyaman. Pelukis dan penggaris tinta sering melakukan ini. Yang berputar hanya tampilan. Gambarnya sendiri tidak berubah.

| Aksi | Pintasan |
| :--- | :--- |
| **Putar tanpa meninggalkan alat yang sedang dipakai** | Tahan `R` dan seret |
| **Putar tampilan** | `Shift` + klik tengah dan seret |
| **Putar tampilan** | `Ctrl` + klik kanan dan seret |
| **Kunci seretan itu ke langkah 15°** | `Shift` + `Ctrl` sambil menyeret |
| **Biarkan Putar tampilan tetap dipilih** | Klik **Putar tampilan**, lalu seret. `Shift` mengunci ke 15°. `Esc` atau **Atur ulang tampilan** mengembalikan ke 0° |

`R` saja tidak bisa dipetakan ulang di **Edit → Pintasan Keyboard**. `Shift` + `R` adalah seleksi persegi panjang.

## Konfigurasi

Untuk melihat atau memetakan ulang pintasan yang ada, buka:

**Edit → Pintasan Keyboard**

Pintasan ditulis begitu Anda menetapkannya, selama **Simpan pintasan papan ketik saat keluar** aktif. Opsi ini aktif secara bawaan.

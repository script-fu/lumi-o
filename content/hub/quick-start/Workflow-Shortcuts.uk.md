Lumi-o створено для робочого процесу на комбінаціях клавіш. Коли ці команди запам’ятаються, навігація полотном і інструментами стає значно швидшою.

## Основні елементи керування полотном

| Дія | Комбінація |
| :--- | :--- |
| **Змінити розмір пензля** | `Alt` + клацнути правою кнопкою та перетягнути |
| **Перемикання між шарами** | `Alt` + навести курсор на полотно |



{{< callout type="info" >}}
**Порада: конфлікт клавіші Alt у Linux**

Якщо `Alt` + перетягування правою кнопкою миші не змінює розмір пензлів у Lumi, стільниця використовує Alt для керування вікнами.

1. Знайдіть **Вікна** у системному меню.
2. Вікна → Поведінка → Спеціальний клавіш для пересування та зміни розміру вікон → **Вимкнено**

Після цієї зміни `Alt` + перетягування правою кнопкою миші має працювати в Lumi для зміни розміру інструментів.
{{< /callout >}}

## Переміщення полотном

Зсув і масштаб залишають вибраним поточний інструмент.

| Дія | Комбінація |
| :--- | :--- |
| **Зсунути** | Середня кнопка й перетягування |
| **Зсунути** | Утримуйте `Space` і перетягуйте |
| **Масштаб** | `Ctrl` + середня кнопка й перетягування |

`Space` за замовчуванням зсуває вигляд.

## Поворот вигляду

Поверніть полотно, щоб відпрацьований штрих ішов у зручний бік. Живописці й тушисти роблять це часто. Повертається лише вигляд. Саме зображення не змінюється.

| Дія | Комбінація |
| :--- | :--- |
| **Повернути, не залишаючи поточний інструмент** | Утримуйте `R` і перетягуйте |
| **Повернути вигляд** | `Shift` + середня кнопка й перетягування |
| **Повернути вигляд** | `Ctrl` + права кнопка й перетягування |
| **Крок цього перетягування 15°** | `Shift` + `Ctrl` під час перетягування |
| **Лишити «Поворот вигляду» вибраним** | Натисніть **Поворот вигляду** і перетягуйте. `Shift` фіксує крок 15°. `Esc` або **Скинути вигляд** повертає 0° |

Саму клавішу `R` не можна призначити в **Редагувати → Комбінації клавіш**. `Shift` + `R` — прямокутне виділення.

## Налаштування

Щоб переглянути або змінити існуючі прив’язки, перейдіть до:

**Редагувати → Комбінації клавіш**

Комбінація записується одразу, поки увімкнено **Зберігати комбінації клавіш при виході**. Цей параметр увімкнено за замовчуванням.

Lumi-o створено для робочого процесу на комбінаціях клавіш. Коли ці команди запам’ятаються, навігація полотном і інструментами стає значно швидшою.

## Основні елементи керування полотном

| Дія | Комбінація |
| :--- | :--- |
| **Змінити розмір пензля** | `Alt` + клацнути правою кнопкою та перетягнути |
| **Перемикання між шарами** | `Alt` + навести курсор на полотно |



{{< callout type="info" >}}
**Порада: конфлікт клавіші Alt у Linux**

Якщо `Alt` + перетягування правою кнопкою миші не змінює розмір пензлів у Lumi, стільниця використовує Alt для керування вікнами.

1. Знайдіть **Вікна** у системному меню.
2. Вікна → Поведінка → Спеціальний клавіш для пересування та зміни розміру вікон → **Вимкнено**

Після цієї зміни `Alt` + перетягування правою кнопкою миші має працювати в Lumi для зміни розміру інструментів.
{{< /callout >}}

## Налаштування та збереження

Щоб переглянути або змінити існуючі прив’язки, перейдіть до:

**Редагувати → Комбінації клавіш**

> **Примітка щодо збереження:** користувацькі комбінації клавіш записуються у файл конфігурації лише після коректного **Файл → Вийти**. Після значних змін закрийте програму через меню, щоб налаштування збереглися.

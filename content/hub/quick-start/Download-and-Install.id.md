Jika Anda sudah menggunakan Linux dan ingin menjalankan Lumi dengan cepat, gunakan **AppImage pengembangan** terbaru dari artefak GitLab:

https://gitlab.gnome.org/pixelmixer/lumi-dev/-/artifacts

1. Unduh zip artefak AppImage pengembangan terbaru.
2. Ekstrak zip-nya.
3. Klik dua kali file `Lumi*.AppImage` untuk menjalankannya.

AppImage seharusnya sudah dapat dijalankan. Jika belum, aktifkan **Izinkan mengeksekusi file sebagai program** pada izin file, atau gunakan metode terminal di bawah.

```bash
chmod +x Lumi*.AppImage
./Lumi*.AppImage
```

Lumi-o สร้างขึ้นสำหรับเวิร์กโฟลว์ที่ขับเคลื่อนด้วยทางลัด เมื่อคุณสร้างหน่วยความจำของกล้ามเนื้อสำหรับคำสั่งเหล่านี้ คุณสามารถนำทางผืนผ้าใบและเครื่องมือของคุณได้เร็วขึ้นอย่างมาก

## การควบคุม Canvas ที่จำเป็น

| การกระทำ | ทางลัด |
| :--- | :--- |
| **ปรับขนาดแปรง** | `Alt` + คลิกขวา & ลาก |
| **วนรอบเลือกเลเยอร์** | `Alt` + โฮเวอร์เหนือแคนวาส |



{{< callout type="info" >}}
**เคล็ดลับ: ความขัดแย้งของปุ่ม Alt บน Linux**

หาก `Alt` + คลิกขวาแล้วลาก ไม่ปรับขนาดแปรงใน Lumi แสดงว่าระบบเดสก์ท็อปใช้ Alt สำหรับการจัดการหน้าต่าง

1. ค้นหา **หน้าต่าง** ในเมนูระบบ
2. หน้าต่าง → ลักษณะการทำงาน → ปุ่มพิเศษที่ใช้ย้ายและปรับขนาดหน้าต่าง → **ปิดใช้งานแล้ว**

หลังจากการเปลี่ยนแปลงนี้ `Alt` + คลิกขวาแล้วลาก ควรใช้งานได้ใน Lumi สำหรับการปรับขนาดเครื่องมือ
{{< /callout >}}

## เลื่อนไปบนแคนวาส

การเลื่อนและการซูมไม่เปลี่ยนเครื่องมือที่เลือกอยู่

| การกระทำ | ทางลัด |
| :--- | :--- |
| **เลื่อน** | คลิกกลางแล้วลาก |
| **เลื่อน** | กด `Space` ค้างแล้วลาก |
| **ซูม** | `Ctrl` + คลิกกลางแล้วลาก |

`Space` ใช้เลื่อนมุมมองเป็นค่าเริ่มต้น

## หมุนมุมมอง

หมุนแคนวาสให้เส้นที่ฝึกมาแล้ววิ่งไปในทิศที่ถนัด นักวาดและนักลงหมึกใช้บ่อย สิ่งที่หมุนคือมุมมองเท่านั้น ตัวภาพไม่เปลี่ยน

| การกระทำ | ทางลัด |
| :--- | :--- |
| **หมุนโดยไม่ออกจากเครื่องมือปัจจุบัน** | กด `R` ค้างแล้วลาก |
| **หมุนมุมมอง** | `Shift` + คลิกกลางแล้วลาก |
| **หมุนมุมมอง** | `Ctrl` + คลิกขวาแล้วลาก |
| **จัดระยะลากนั้นทีละ 15°** | กด `Shift` + `Ctrl` ขณะลาก |
| **ให้หมุนมุมมองถูกเลือกค้างไว้** | คลิก **หมุนมุมมอง** แล้วลาก `Shift` จัดเป็นขั้น 15° `Esc` หรือ **รีเซ็ตมุมมอง** กลับไปที่ 0° |

`R` เปล่าๆ กำหนดใหม่ใน **แก้ไข → แป้นพิมพ์ลัด** ไม่ได้ `Shift` + `R` คือการเลือกสี่เหลี่ยม

## การกำหนดค่า

หากต้องการดูหรือแมปการเชื่อมโยงที่มีอยู่ใหม่ ให้ไปที่:

**แก้ไข → แป้นพิมพ์ลัด**

ทางลัดถูกเขียนทันทีที่คุณตั้ง ขณะที่ **บันทึกปุ่มลัดแป้นพิมพ์เมื่อออก** เปิดอยู่ ตัวเลือกนี้เปิดอยู่เป็นค่าเริ่มต้น

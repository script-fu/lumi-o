Lumi-o 專為快捷方式驅動的工作流程而設計。一旦您建立了這些命令的肌肉記憶，您就可以更快地導航畫布和工具。

## 基本畫布控件

|行動|捷徑 |
| :--- | :--- |
| **調整畫筆大小** | `Alt` + 右鍵單擊並拖曳 |
| **循環選擇圖層** | `Alt` + 將滑鼠懸停在畫布上 |



{{< callout type="info" >}}
**提示：Linux 上的 Alt 鍵衝突**

如果在 Lumi 中 `Alt` + 右鍵拖曳無法調整筆刷大小，表示桌面正在將 Alt 用於視窗管理。

1. 在系統選單中搜尋 **視窗**。
2. 視窗 → 行為 → 用特殊鍵移動視窗與重新調整尺寸 → **已停用**

完成此變更後，`Alt` + 右鍵拖曳應可在 Lumi 中用於調整工具大小。
{{< /callout >}}

## 在畫布上移動

平移和縮放都保持目前工具不變。

|行動|捷徑 |
| :--- | :--- |
| **平移** | 中鍵單擊並拖曳 |
| **平移** | 按住 `Space` 並拖曳 |
| **縮放** | `Ctrl` + 中鍵單擊並拖曳 |

`Space` 預設用來平移。

## 旋轉檢視

把畫布轉一下，讓已經練熟的一筆沿著順手的方向出去。畫師和勾線的人經常這樣做。轉的只是檢視。影像本身不變。

|行動|捷徑 |
| :--- | :--- |
| **不離開目前工具時旋轉** | 按住 `R` 並拖曳 |
| **旋轉檢視** | `Shift` + 中鍵單擊並拖曳 |
| **旋轉檢視** | `Ctrl` + 右鍵單擊並拖曳 |
| **這次拖曳以 15° 對齊** | 拖曳時按住 `Shift` + `Ctrl` |
| **保持選取旋轉檢視** | 點 **旋轉檢視** 再拖曳。`Shift` 以 15° 對齊。`Esc` 或 **重設檢視** 回到 0° |

單獨的 `R` 不能在 **編輯 → 鍵盤快速鍵** 裡改派。`Shift` + `R` 是矩形選取。

## 設定

若要查看或重新對應現有綁定，請導覽至：

**編輯 → 鍵盤快速鍵**

快捷鍵在你設定時就會寫入，只要 **結束時儲存鍵盤快捷鍵** 是開啟的。這項預設是開啟的。

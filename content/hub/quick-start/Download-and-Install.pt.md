Se já usa Linux e pretende executar o Lumi rapidamente, use o **AppImage de desenvolvimento** mais recente a partir dos artefactos do GitLab:

https://gitlab.gnome.org/pixelmixer/lumi-dev/-/artifacts

1. Descarregue o zip do artefacto AppImage de desenvolvimento mais recente.
2. Extraia o zip.
3. Faça duplo clique no ficheiro `Lumi*.AppImage` para o executar.

O AppImage já deve ser executável. Se não o for, active **Permitir executar o ficheiro como programa** nas permissões do ficheiro, ou use o método de terminal abaixo.

```bash
chmod +x Lumi*.AppImage
./Lumi*.AppImage
```

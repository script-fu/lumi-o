Lumi-o создан для рабочего процесса с использованием ярлыков. Как только вы наладите мышечную память на эти команды, вы сможете перемещаться по холсту и инструментам значительно быстрее.

## Основные элементы управления холстом

| Действие | Ярлык |
| :--- | :--- |
| **Регулировка размера кисти** | `Alt` + Щелкните правой кнопкой мыши и перетащите |
| **Циклический выбор слоев** | `Alt` + Наведите курсор на холст |



{{< callout type="info" >}}
**Совет: конфликт клавиши Alt в Linux**

Если `Alt` + перетаскивание правой кнопкой мыши не изменяет размер кистей в Lumi, рабочий стол использует Alt для управления окнами.

1. Найдите **Окна** в системном меню.
2. Окна → Поведение → Специальная клавиша для перемещения и изменения размеров окон → **Отключено**

После этого изменения `Alt` + перетаскивание правой кнопкой мыши должно работать в Lumi для изменения размера инструментов.
{{< /callout >}}

## Перемещение по холсту

Сдвиг и масштаб оставляют выбранным текущий инструмент.

| Действие | Ярлык |
| :--- | :--- |
| **Сдвинуть** | Средняя кнопка и перетаскивание |
| **Сдвинуть** | Удерживайте `Space` и перетаскивайте |
| **Масштаб** | `Ctrl` + средняя кнопка и перетаскивание |

`Space` по умолчанию сдвигает вид.

## Поворот вида

Поверните холст, чтобы отработанный штрих шёл в удобную сторону. Живописцы и тушисты делают это часто. Поворачивается только вид. Само изображение не меняется.

| Действие | Ярлык |
| :--- | :--- |
| **Повернуть, не оставляя текущий инструмент** | Удерживайте `R` и перетаскивайте |
| **Повернуть вид** | `Shift` + средняя кнопка и перетаскивание |
| **Повернуть вид** | `Ctrl` + правая кнопка и перетаскивание |
| **Шаг этого перетаскивания 15°** | `Shift` + `Ctrl` во время перетаскивания |
| **Оставить «Поворот вида» выбранным** | Нажмите **Поворот вида** и перетаскивайте. `Shift` фиксирует шаг 15°. `Esc` или **Сбросить вид** возвращает 0° |

Одну клавишу `R` нельзя назначить в **Правка → Сочетания клавиш**. `Shift` + `R` — прямоугольное выделение.

## Настройка

Чтобы просмотреть или переназначить существующие привязки, перейдите к:

**Правка → Сочетания клавиш**

Сочетание записывается сразу, пока включено **Сохранять комбинации клавиш при выходе**. Этот параметр включён по умолчанию.

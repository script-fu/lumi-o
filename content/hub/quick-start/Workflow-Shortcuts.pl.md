Lumi-o został stworzony z myślą o przepływie pracy opartym na skrótach. Gdy już ustalisz pamięć mięśniową dla tych poleceń, będziesz mógł znacznie szybciej poruszać się po obszarze roboczym i narzędziach.

## Niezbędne elementy sterujące płótna

| Akcja | Skrót |
| :--- | :--- |
| **Dostosuj rozmiar pędzla** | `Alt` + Kliknij prawym przyciskiem myszy i przeciągnij |
| **Wybieraj cyklicznie warstwy** | `Alt` + Najedź kursorem na płótno |



{{< callout type="info" >}}
**Wskazówka: konflikt klawisza Alt w systemie Linux**

Jeśli `Alt` + przeciąganie prawym przyciskiem myszy nie zmienia rozmiaru pędzli w Lumi, pulpit używa Alt do zarządzania oknami.

1. Wyszukaj **Okna** w menu systemowym.
2. Okna → Zachowanie → Specjalny przycisk do przenoszenia i zmieniania rozmiaru okien → **Nieaktywne**

Po tej zmianie `Alt` + przeciąganie prawym przyciskiem myszy powinno działać w Lumi do zmiany rozmiaru narzędzi.
{{< /callout >}}

## Poruszanie po płótnie

Przesuwanie i powiększanie zostawiają wybrane bieżące narzędzie.

| Akcja | Skrót |
| :--- | :--- |
| **Przesuń** | Klik środkowym i przeciągnij |
| **Przesuń** | Przytrzymaj `Space` i przeciągnij |
| **Powiększ** | `Ctrl` + klik środkowym i przeciągnij |

`Space` domyślnie przesuwa widok.

## Obróć widok

Obróć płótno, żeby wyćwiczone pociągnięcie szło w wygodnym kierunku. Malarze i rysownicy tuszem robią to często. Obraca się tylko widok. Obraz się nie zmienia.

| Akcja | Skrót |
| :--- | :--- |
| **Obracaj bez opuszczania bieżącego narzędzia** | Przytrzymaj `R` i przeciągnij |
| **Obróć widok** | `Shift` + klik środkowym i przeciągnij |
| **Obróć widok** | `Ctrl` + klik prawym i przeciągnij |
| **Zatrzaskuj to przeciągnięcie co 15°** | `Shift` + `Ctrl` podczas przeciągania |
| **Zostaw narzędzie Obróć widok** | Kliknij **Obróć widok**, potem przeciągnij. `Shift` zatrzaskuje co 15°. `Esc` albo **Resetuj widok** wraca do 0° |

Samego `R` nie da się przypisać w **Edycja → Skróty klawiaturowe**. `Shift` + `R` to zaznaczenie prostokątne.

## Konfiguracja

Aby wyświetlić lub ponownie przypisać istniejące powiązania, przejdź do:

**Edycja → Skróty klawiaturowe**

Zmiana skrótu jest zapisywana od razu, gdy **Zapisywanie skrótów przed zakończeniem** jest włączone. Ta opcja jest włączona domyślnie.

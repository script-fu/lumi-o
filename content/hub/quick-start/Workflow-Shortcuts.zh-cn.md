Lumi-o 专为快捷方式驱动的工作流程而设计。一旦您建立了这些命令的肌肉记忆，您就可以更快地导航画布和工具。

## 基本画布控件

|行动|快捷方式 |
| :--- | :--- |
| **调整画笔大小** | `Alt` + 右键单击并拖动 |
| **循环选择图层** | `Alt` + 将鼠标悬停在画布上 |



{{< callout type="info" >}}
**提示：Linux 上的 Alt 键冲突**

如果在 Lumi 中 `Alt` + 右键拖动无法调整画笔大小，说明桌面正在将 Alt 用于窗口管理。

1. 在系统菜单中搜索 **窗口**。
2. 窗口 → 行为 → 窗口移动和调整大小的特殊键 → **已禁用**

完成此更改后，`Alt` + 右键拖动应可在 Lumi 中用于调整工具大小。
{{< /callout >}}

## 在画布上移动

平移和缩放都保持当前工具不变。

|行动|快捷方式 |
| :--- | :--- |
| **平移** | 中键单击并拖动 |
| **平移** | 按住 `Space` 并拖动 |
| **缩放** | `Ctrl` + 中键单击并拖动 |

`Space` 默认用来平移。

## 旋转视图

把画布转一下，让已经练熟的一笔沿顺手的方向出去。画师和勾线的人经常这么做。转的只是视图。图像本身不变。

|行动|快捷方式 |
| :--- | :--- |
| **不离开当前工具时旋转** | 按住 `R` 并拖动 |
| **旋转视图** | `Shift` + 中键单击并拖动 |
| **旋转视图** | `Ctrl` + 右键单击并拖动 |
| **这次拖动按 15° 对齐** | 拖动时按住 `Shift` + `Ctrl` |
| **保持选中旋转视图** | 点击 **旋转视图** 再拖动。`Shift` 按 15° 对齐。`Esc` 或 **重置视图** 回到 0° |

单独的 `R` 不能在 **编辑 → 键盘快捷键** 里改派。`Shift` + `R` 是矩形选择。

## 配置

要查看或重新映射现有绑定，请导航至：

**编辑 → 键盘快捷键**

快捷键在你设定时就会写入，只要 **退出时保存快捷键** 是打开的。这项默认是打开的。

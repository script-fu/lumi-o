Lumi-o 专为快捷方式驱动的工作流程而设计。一旦您建立了这些命令的肌肉记忆，您就可以更快地导航画布和工具。

## 基本画布控件

|行动|快捷方式 |
| :--- | :--- |
| **调整画笔大小** | `Alt` + 右键单击并拖动 |
| **循环选择图层** | `Alt` + 将鼠标悬停在画布上 |



{{< callout type="info" >}}
**提示：Linux 上的 Alt 键冲突**

如果在 Lumi 中 `Alt` + 右键拖动无法调整画笔大小，说明桌面正在将 Alt 用于窗口管理。

1. 在系统菜单中搜索 **窗口**。
2. 窗口 → 行为 → 窗口移动和调整大小的特殊键 → **已禁用**

完成此更改后，`Alt` + 右键拖动应可在 Lumi 中用于调整工具大小。
{{< /callout >}}

## 配置和持久化

要查看或重新映射现有绑定，请导航至：

**编辑 → 键盘快捷键**

> **关于持久性的注意事项：** 您的自定义快捷方式配置仅在正确的 **文件→退出** 时才会提交到您的配置文件。请确保在进行重大更改后通过菜单关闭应用程序，以确保您的设置得到保留。

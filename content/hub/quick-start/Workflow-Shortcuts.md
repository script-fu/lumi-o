Lumi-o is built for a shortcut-driven workflow. Once you establish muscle memory for these commands, you can navigate your canvas and tools significantly faster.

## Essential Canvas Controls

| Action | Shortcut |
| :--- | :--- |
| **Adjust Brush Size** | `Alt` + Right Click & Drag |
| **Cycle Select Layers** | `Alt` + Hover over canvas |

{{< callout type="info" >}}
**Tip: Alt Key Conflict on Linux**

If `Alt` + Right Click Drag does not resize brushes in Lumi, the desktop is using Alt for window management.

1. Search the system menu for **Windows**.
2. Windows → Behaviour → Special key to move and resize windows → **Disabled**

After this change, `Alt` + Right Click Drag should work in Lumi for tool resizing.
{{< /callout >}}

## Move around the canvas

Pan and zoom leave the current tool selected.

| Action | Shortcut |
| :--- | :--- |
| **Pan** | Middle Click & Drag |
| **Pan** | Hold `Space` and drag |
| **Zoom** | `Ctrl` + Middle Click & Drag |

`Space` pans by default.

## Rotate the View

Turn the canvas so a practiced stroke runs in a comfortable direction. Painters and inkers do this often. Only the view turns. The image is not changed.

| Action | Shortcut |
| :--- | :--- |
| **Rotate without leaving the current tool** | Hold `R` and drag |
| **Rotate the view** | `Shift` + Middle Click & Drag |
| **Rotate the view** | `Ctrl` + Right Click & Drag |
| **Snap that drag to 15°** | `Shift` + `Ctrl` while dragging |
| **Keep Rotate View selected** | Click **Rotate View**, then drag. `Shift` snaps to 15°. `Esc` or **Reset View** returns to 0° |

Plain `R` cannot be remapped under **Edit → Keyboard Shortcuts**. `Shift` + `R` is Rectangle Select.

## Configuration

To view or remap your existing bindings, navigate to:

**Edit → Keyboard Shortcuts**

A shortcut change is written as soon as you set it, while **Save keyboard shortcuts on exit** is on. That option is on by default.

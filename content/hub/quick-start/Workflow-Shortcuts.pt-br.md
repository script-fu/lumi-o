O Lumi-o foi desenvolvido para um fluxo de trabalho baseado em atalhos. Depois de estabelecer a memória muscular para esses comandos, você poderá navegar pela tela e pelas ferramentas com muito mais rapidez.

## Controles essenciais do Canvas

| Ação | Atalho |
| :--- | :--- |
| **Ajustar o tamanho do pincel** | `Alt` + Clique com o botão direito e arraste |
| **Ciclar camadas selecionadas** | `Alt` + Passe o mouse sobre a tela |



{{< callout type="info" >}}
**Dica: conflito da tecla Alt no Linux**

Se `Alt` + clique com o botão direito e arrastar não redimensionar os pincéis no Lumi, a área de trabalho está usando Alt para o gerenciamento de janelas.

1. Pesquise por **Janelas** no menu do sistema.
2. Janelas → Comportamento → Tecla especial para mover e redimensionar janelas → **Desativado**

Após essa alteração, `Alt` + clique com o botão direito e arrastar deve funcionar no Lumi para redimensionar ferramentas.
{{< /callout >}}

## Mover-se na tela

Deslocar e dar zoom deixam a ferramenta atual selecionada.

| Ação | Atalho |
| :--- | :--- |
| **Deslocar** | Clique com o botão do meio e arraste |
| **Deslocar** | Segure `Space` e arraste |
| **Zoom** | `Ctrl` + clique com o botão do meio e arraste |

`Space` desloca a vista por padrão.

## Girar a vista

Gire a tela para que um traço já treinado saia numa direção confortável. Pintores e arte-finalistas fazem isso com frequência. Só a vista gira. A imagem não muda.

| Ação | Atalho |
| :--- | :--- |
| **Girar sem sair da ferramenta atual** | Segure `R` e arraste |
| **Girar a vista** | `Shift` + clique com o botão do meio e arraste |
| **Girar a vista** | `Ctrl` + clique com o botão direito e arraste |
| **Encaixar esse arraste em passos de 15°** | `Shift` + `Ctrl` enquanto arrasta |
| **Manter Girar a vista selecionada** | Clique em **Girar a vista** e arraste. `Shift` encaixa em 15°. `Esc` ou **Redefinir a vista** volta a 0° |

`R` sozinho não pode ser reatribuído em **Editar → Atalhos de teclado**. `Shift` + `R` é a seleção retangular.

## Configuração

Para visualizar ou remapear suas vinculações existentes, navegue até:

**Editar → Atalhos de teclado**

Uma alteração de atalho é gravada assim que você a define, enquanto **Salvar atalhos de teclado ao sair** estiver marcado. A opção vem marcada.

Lumi-o は、ショートカット主導のワークフロー向けに構築されています。これらのコマンドの筋肉の記憶を確立すると、キャンバスとツールを大幅に高速に操作できるようになります。

## 必須のキャンバス コントロール

|アクション |ショートカット |
| :--- | :--- |
| **ブラシ サイズを調整** | `Alt` + 右クリックしてドラッグ |
| **レイヤー選択のサイクル** | `Alt` + キャンバスの上にマウスを移動します |



{{< callout type="info" >}}
**ヒント: Linux での Alt キーの競合**

Lumi で `Alt` + 右クリックドラッグでブラシのサイズが変わらない場合、デスクトップがウィンドウ管理に Alt を使っています。

1. システムメニューで **ウィンドウ** を検索します。
2. ウィンドウ → 振る舞い → ウィンドウの移動とサイズ変更に使用する特定キー → **無効**

この変更後、Lumi でツールのサイズ変更に `Alt` + 右クリックドラッグが使えるようになります。
{{< /callout >}}

## キャンバス上を移動

パンとズームは、今のツールを選んだまま行います。

|アクション |ショートカット |
| :--- | :--- |
| **パン** | 中クリックしてドラッグ |
| **パン** | `Space` を押したままドラッグ |
| **ズーム** | `Ctrl` + 中クリックしてドラッグ |

`Space` は既定でパンします。

## ビューを回転

身についた一筆が引きやすい向きになるよう、キャンバスを回します。ペインターやインカーがよく使う操作です。回るのは表示だけです。画像そのものは変わりません。

|アクション |ショートカット |
| :--- | :--- |
| **今のツールのまま回転** | `R` を押したままドラッグ |
| **ビューを回転** | `Shift` + 中クリックしてドラッグ |
| **ビューを回転** | `Ctrl` + 右クリックしてドラッグ |
| **そのドラッグを 15° 刻みに** | ドラッグ中に `Shift` + `Ctrl` |
| **「ビューを回転」を選んだままにする** | **ビューを回転** をクリックしてからドラッグ。`Shift` は 15° にスナップ。`Esc` または **ビューをリセット** で 0° に戻る |

`R` 単体は **編集 → キーボード ショートカット** では割り当てられません。`Shift` + `R` は矩形選択です。

## 設定

既存のバインディングを表示または再マッピングするには、次の場所に移動します。

**編集 → キーボード ショートカット**

ショートカットは設定した直後に書き込まれます。**終了時にキーボードショートカットを保存する** がオンのときです。この項目は既定でオンです。

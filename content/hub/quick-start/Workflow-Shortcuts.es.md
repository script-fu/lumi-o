Lumi-o está diseñado para un flujo de trabajo basado en atajos. Una vez que establezca la memoria muscular para estos comandos, podrá navegar por su lienzo y sus herramientas mucho más rápido.

## Controles esenciales del lienzo

| Acción | Atajo |
| :--- | :--- |
| **Ajustar tamaño del pincel** | `Alt` + Clic derecho y arrastrar |
| **Ciclo de selección de capas** | `Alt` + Coloca el cursor sobre el lienzo |



{{< callout type="info" >}}
**Consejo: conflicto de la tecla Alt en Linux**

Si `Alt` + clic derecho y arrastrar no redimensiona los pinceles en Lumi, el escritorio está usando Alt para la gestión de ventanas.

1. Busca **Ventanas** en el menú del sistema.
2. Ventanas → Comportamiento → Tecla especial para mover y redimensionar ventanas → **Desactivar**

Tras este cambio, `Alt` + clic derecho y arrastrar debería funcionar en Lumi para redimensionar herramientas.
{{< /callout >}}

## Moverse por el lienzo

Desplazar y hacer zoom dejan seleccionada la herramienta actual.

| Acción | Atajo |
| :--- | :--- |
| **Desplazar** | Clic central y arrastrar |
| **Desplazar** | Mantén `Space` y arrastra |
| **Zoom** | `Ctrl` + clic central y arrastrar |

`Space` desplaza de forma predeterminada.

## Girar la vista

Gira el lienzo para que un trazo ya practicado salga en una dirección cómoda. Pintores y entintadores lo hacen a menudo. Solo gira la vista. La imagen no cambia.

| Acción | Atajo |
| :--- | :--- |
| **Girar sin dejar la herramienta actual** | Mantén `R` y arrastra |
| **Girar la vista** | `Shift` + clic central y arrastrar |
| **Girar la vista** | `Ctrl` + clic derecho y arrastrar |
| **Ajustar ese arrastre a pasos de 15°** | `Shift` + `Ctrl` mientras arrastras |
| **Dejar Girar vista seleccionado** | Pulsa **Girar vista** y arrastra. `Shift` ajusta a 15°. `Esc` o **Restablecer vista** vuelve a 0° |

`R` sola no se puede reasignar en **Editar → Atajos de teclado**. `Shift` + `R` es la selección rectangular.

## Configuración

Para ver o reasignar sus enlaces existentes, navegue hasta:

**Editar → Atajos de teclado**

Un atajo se guarda en cuanto lo asignas, mientras **Guardar los atajos del teclado al salir** esté activado. Esa opción viene activada.

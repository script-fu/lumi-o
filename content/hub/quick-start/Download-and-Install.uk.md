Якщо ви вже користуєтеся Linux і хочете швидко запустити Lumi, скористайтеся найновішим **розробницьким AppImage** з артефактів GitLab:

https://gitlab.gnome.org/pixelmixer/lumi-dev/-/artifacts

1. Завантажте останній zip-архів з артефактом AppImage розробницької збірки.
2. Розпакуйте архів.
3. Двічі клацніть файл `Lumi*.AppImage`, щоб запустити його.

AppImage має бути готовим до запуску. Якщо ні, увімкніть **Дозволити виконання файлу як програми** в дозволах файлу або скористайтеся методом через термінал нижче.

```bash
chmod +x Lumi*.AppImage
./Lumi*.AppImage
```

Lumi-o는 바로가기 기반 워크플로우를 위해 제작되었습니다. 이러한 명령에 대한 머슬 메모리를 구축하면 캔버스와 도구를 훨씬 더 빠르게 탐색할 수 있습니다.

## 필수 캔버스 컨트롤

| 액션 | 바로가기 |
| :--- | :--- |
| **브러시 크기 조정** | `Alt` + 마우스 오른쪽 버튼을 클릭하고 드래그 |
| **사이클 선택 레이어** | `Alt` + 캔버스 위로 마우스를 가져가세요 |



{{< callout type="info" >}}
**팁: Linux에서 Alt 키 충돌**

Lumi에서 `Alt` + 오른쪽 클릭 드래그로 브러시 크기가 조절되지 않으면, 데스크톱이 Alt를 창 관리에 사용하고 있는 것입니다.

1. 시스템 메뉴에서 **창**을 검색하세요.
2. 창 → 동작 → 창을 이동할 때 사용할 특수 키 → **사용 안함**

이 변경 후 Lumi에서 도구 크기 조절에 `Alt` + 오른쪽 클릭 드래그가 작동해야 합니다.
{{< /callout >}}

## 캔버스에서 이동

패닝과 확대/축소는 현재 도구를 선택한 채로 합니다.

| 액션 | 바로가기 |
| :--- | :--- |
| **패닝** | 가운데 클릭 후 드래그 |
| **패닝** | `Space`를 누른 채 드래그 |
| **확대/축소** | `Ctrl` + 가운데 클릭 후 드래그 |

`Space`는 기본적으로 패닝합니다.

## 보기 회전

익힌 선이 편한 방향으로 나가도록 캔버스를 돌립니다. 페인터와 인커가 자주 씁니다. 돌아가는 것은 보기뿐입니다. 이미지 자체는 바뀌지 않습니다.

| 액션 | 바로가기 |
| :--- | :--- |
| **현재 도구를 유지한 채 회전** | `R`을 누른 채 드래그 |
| **보기 회전** | `Shift` + 가운데 클릭 후 드래그 |
| **보기 회전** | `Ctrl` + 오른쪽 클릭 후 드래그 |
| **그 드래그를 15° 단위로** | 드래그하는 동안 `Shift` + `Ctrl` |
| **보기 회전을 선택한 채로** | **보기 회전**을 누른 뒤 드래그합니다. `Shift`는 15°에 맞춥니다. `Esc` 또는 **보기 재설정**은 0°로 되돌립니다 |

`R`만은 **수정 → 키보드 단축키**에서 다른 명령에 넣을 수 없습니다. `Shift` + `R`은 사각형 선택입니다.

## 설정

기존 바인딩을 보거나 다시 매핑하려면 다음으로 이동하세요.

**수정 → 키보드 단축키**

단축키는 지정하는 즉시 저장됩니다. **마칠 때 키보드 단축키 저장**이 켜져 있을 때입니다. 이 옵션은 기본적으로 켜져 있습니다.

«Перші кроки» знайомлять із функціональними шаблонами, які добре працюють у Scheme, через короткі приклади та поступовий рефакторинг.
Наприкінці ви створите власну бібліотеку обміну повідомленнями та отримаєте міцну основу для розробки складніших плагінів.

### Що вам знадобиться

Перед початком переконайтеся, що у вас є:

- Встановлений Lumi (недавня збірка або AppImage).
- Текстовий редактор для файлів `.scm` (VS Code підходить добре): [Visual Studio Code](/hub/scripting/tools/visual-studio-code)
- [Git](/hub/scripting/tools/git/) для резервного копіювання коду та контролю версій.

Langkah Pertama memperkenalkan pola fungsional yang bekerja dengan baik di Scheme, dengan contoh singkat dan pemfaktoran ulang tambahan.
Pada akhirnya, Anda akan membangun perpustakaan perpesanan khusus Anda sendiri dan memiliki dasar yang kuat untuk terus mengembangkan plug-in yang lebih canggih.

### Yang Anda Butuhkan

Sebelum memulai, pastikan Anda memiliki hal berikut:

- Lumi diinstal (build terbaru atau AppImage).
- Editor teks untuk file `.scm` (VS Code berfungsi dengan baik): [Visual Studio Code](/hub/scripting/tools/visual-studio-code)
- [Git](/hub/scripting/tools/git/) untuk menjaga cadangan kode Anda dan mengontrol versi.

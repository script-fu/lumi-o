조건문은 프로그래밍의 기본 요소입니다. 스크립트가 결정을 내리고 특정 기준에 따라 흐름을 제어할 수 있게 합니다. Scheme 프로그래밍 언어에 기반한 Scheme에서는 조건문을 통해 변화하는 입력, 환경, 사용자 동작에 적응하는 동적이고 지능적인 스크립트를 작성할 수 있습니다.

### Scheme에서 조건문의 역할

조건문은 스크립트에서 여러 핵심 목적을 수행합니다.
- **로직 제어:** 특정 조건의 참·거짓에 따라 서로 다른 코드 블록을 실행합니다.
- **유연성 향상:** 입력이나 상태에 동적으로 반응하여 다양한 시나리오를 처리합니다.
- **복잡성 단순화:** 의사 결정을 관리 가능한 구조로 나누어 코드를 읽고, 디버그하고, 유지하기 쉽게 만듭니다.

### 사용 가능한 조건 구문

Scheme은 각각 다른 논리적 요구에 맞는 여러 조건 구문을 제공합니다.
- **`if`:** 단순한 이항 결정 — 조건이 참이면 한 블록, 거짓이면 다른 블록을 실행합니다.
- **`cond`:** 여러 조건을 명확하고 구조적으로 처리하는 강력한 다중 분기 구문입니다.
- **`and` / `or`:** 조건 조합을 평가하여 더 복잡한 결정을 가능하게 하는 논리 연산자입니다.
- **`else`:** 지정된 조건이 모두 거짓일 때의 대체 동작을 정의합니다.

### 조건문의 동작 방식

조건문은 일반적으로 다음을 포함합니다.
1. **조건 평가:** 테스트 식이 조건의 참·거짓을 판별합니다.
2. **분기 실행:** 평가 결과에 따라 실행할 코드 블록을 선택합니다.
3. **값 반환(선택):** 경우에 따라 스크립트의 다른 부분에서 사용할 값을 반환합니다.

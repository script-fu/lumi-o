Условные конструкции — фундамент программирования: они позволяют сценариям принимать решения и управлять потоком выполнения по заданным критериям. В Scheme, основанном на языке Scheme, условия помогают создавать динамичные, гибкие сценарии, адаптирующиеся к изменяющимся входным данным, среде или действиям пользователя.

### Роль условных конструкций в Scheme

Условия выполняют в сценариях несколько ключевых функций:
- **Управление логикой:** Запускают разные фрагменты кода в зависимости от истинности условий.
- **Гибкость:** Динамически реагируя на входные данные или состояние, помогают обрабатывать множество сценариев.
- **Упрощение сложности:** Разбивают принятие решений на понятные структуры, облегчая чтение, отладку и сопровождение кода.

### Доступные условные конструкции

Scheme предлагает несколько условных конструкций, каждая для своих логических задач:
- **`if`:** Для простых бинарных решений — один блок при истинном условии, другой при ложном.
- **`cond`:** Мощная многоветвевая конструкция для нескольких условий в ясной, структурированной форме.
- **`and` / `or`:** Логические операторы, оценивающие комбинации условий для более сложных решений.
- **`else`:** Запасной вариант, определяющий поведение, когда ни одно из указанных условий не выполнено.

### Как работают условные конструкции

Условия обычно включают:
1. **Оценку условия:** Тестовое выражение определяет, истинно условие или ложно.
2. **Ветвление:** По результату оценки сценарий выбирает блок кода для выполнения.
3. **Возврат значения (необязательно):** В некоторых случаях условие также возвращает значение для других частей сценария.

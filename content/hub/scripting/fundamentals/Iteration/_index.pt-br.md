A iteração é um pilar da programação: permite que scripts repitam ações e processem coleções de dados com eficiência. Em Scheme, a iteração oferece ferramentas para automatizar tarefas repetitivas, manipular estruturas de dados e criar padrões de execução sofisticados.

### O papel da iteração em Scheme

A iteração cumpre várias funções essenciais nos seus scripts:
- **Automatizar repetição:** Executar a mesma ação ou conjunto de ações várias vezes sem duplicar código.
- **Aumentar a eficiência:** Ao processar estruturas de dados de forma iterativa, os scripts podem lidar com operações em larga escala de maneira sistemática.
- **Simplificar o código:** A iteração elimina redundância, tornando o código mais conciso, legível e fácil de manter.

### Tipos de iteração disponíveis

Scheme oferece várias construções de iteração, cada uma adaptada a necessidades específicas:
- **map:** Aplica uma função a cada elemento de uma lista, retornando uma nova lista com os resultados.
- **for-each:** Semelhante a `map`, mas usado para executar uma função em cada elemento sem retornar um resultado.
- **do:** Uma construção de loop de propósito geral que lida com uma ampla variedade de processos iterativos.
- **recursion:** Uma técnica poderosa em que funções chamam a si mesmas para resolver problemas de forma incremental.

### Como a iteração funciona

A iteração geralmente envolve:
1. **Definir a repetição:** Especificar a ação a repetir e os dados ou o intervalo a processar.
2. **Executar em sequência:** Repetir a ação para cada elemento, passo ou condição até a conclusão.
3. **Retornar um resultado (opcional):** Dependendo da construção, a iteração pode produzir um resultado ou modificar o estado.

Essas construções permitem escrever scripts adaptáveis, eficientes e elegantes que lidam com tarefas complexas com facilidade.

Ітерація — основа програмування: вона дозволяє скриптам повторювати дії та ефективно обробляти колекції даних. У Scheme ітерація дає інструменти для автоматизації повторюваних завдань, маніпулювання структурами даних і створення складних шаблонів виконання.

### Роль ітерації в Scheme

Ітерація виконує кілька основних цілей:
- **Автоматизація повторення:** виконання тієї самої дії кілька разів без дублювання коду.
- **Ефективність:** послідовна обробка структур даних для систематичних масштабних операцій.
- **Стислість коду:** ітерація усуває надмірність, роблячи код лаконічнішим, читабельнішим і підтримуваним.

### Доступні типи ітерації

Scheme пропонує кілька конструкцій ітерації:
- **`map`:** застосовує функцію до кожного елемента списку, повертаючи новий список результатів.
- **`for-each`:** подібно до `map`, але виконує функцію для кожного елемента без повернення результату.
- **`do`:** універсальна конструкція циклу для широкого спектра ітераційних процесів.
- **Рекурсія:** потужна техніка, коли функції викликають самі себе для поступового вирішення задач.

### Як працює ітерація

Зазвичай це включає:
1. **Визначення повторення:** дія для повторення та дані або діапазон для обробки.
2. **Послідовне виконання:** повторення дії для кожного елемента, кроку або умови до завершення.
3. **Повернення результату (необов’язково):** залежно від конструкції ітерація може повертати результат або змінювати стан.

Ці конструкції дають змогу писати адаптивні, ефективні та елегантні скрипти для складних завдань.

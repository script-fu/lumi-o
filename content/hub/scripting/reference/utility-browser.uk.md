Оглядач утиліт дозволяє досліджувати вбудовану stdlib утиліт Scheme, яка постачається разом із Lumi, не виходячи з програми та не копаючись у вихідних файлах.

## Відкриття оглядача утиліт

Перейдіть до **Довідка → Програмування → Оглядач утиліт**.

Вікно відкривається одразу — плагін не потрібно завантажувати заздалегідь.

## Що він показує

Оглядач перераховує кожну процедуру, змінну та синтаксичну форму, експортовану сімома бібліотеками утиліт, які Lumi автоматично завантажує під час запуску:

| Бібліотека | Що охоплює |
|---|---|
| `common.scm` | Помічники загального призначення (утиліти для рядків, чисел, списків) |
| `files.scm` | Помічники для файлів і шляхів |
| `gegl.scm` | Буфер GEGL і помічники для кольорів |
| `images.scm` | Помічники на рівні зображення (`image-get-open-list` тощо) |
| `layers.scm` | Помічники для шарів і drawable |
| `parasites.scm` | Помічники для читання/запису parasites |
| `paths.scm` | Помічники для шляхів і векторів |

Усе це доступно в будь-якому плагіні Scheme або в консолі Scheme.

## Пошук і фільтрація

- **Поле пошуку**: фільтрує за назвою під час введення (збіг підрядка без урахування регістру).
- **Фільтр типу**: звужує результати до `procedure`, `variable` або `syntax`.

Клацніть запис, щоб побачити повний рядок документації та бібліотеку, з якої він походить.

## Stdlib як обгортки

Бібліотеки утиліт — практичне застосування шаблону обгортки: кожен помічник дає чітку назву низькорівневій операції, приховує шаблонний код і надає єдине місце для оновлення, якщо базова команда змінюється. Щоб зрозуміти підхід до дизайну, перегляньте посібник **[Обгортання]({{< ref "/hub/scripting/tutorials/Wrapping/wrapping" >}})**.

## Зв’язок з оглядачем процедур

Оглядач утиліт відокремлений від **Оглядача процедур** (консоль Scheme → Browse). Оглядач процедур перелічує процедури, зареєстровані в PDB. Оглядач утиліт перелічує допоміжні визначення, які навмисно живуть *поза* PDB: вони є лише Scheme і не мають зв’язку з C.

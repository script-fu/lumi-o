## Що таке Visual Studio Code?

[Visual Studio Code](https://code.visualstudio.com/) (часто скорочено «VS Code» або «VSC») — безкоштовний текстовий редактор з відкритим кодом від Microsoft, створений для програмування. Він легкий, швидкий і налаштовуваний, тому є одним із найпопулярніших редакторів коду. Ось чому VSC — хороший вибір:

- **Підсвічування синтаксису**: розфарбовує код кольорами, що полегшує помітити помилки, зрозуміти структуру та читати складний код.
- **Розширення**: VSC можна розширити тисячами розширень — підтримка мов, тем, інструментів тощо.
- **Інтеграція з контролем версій**: вбудована підтримка Git полегшує відстеження змін і роботу з гілками через [GitHub](https://github.com/) або [GitLab](https://gitlab.com/).

### Основні можливості для початківців

- **Робочі області**: VSC дозволяє організовувати кілька проєктів у «робочих областях», де пов’язані файли та папки зберігаються разом для зручної навігації.

- **Профілі**: профілі дають різні налаштування для різних проєктів або завдань — наприклад, окремий профіль для веб-розробки та інший для Scheme, кожен зі своїми розширеннями, темами та параметрами.

### Початок роботи з Visual Studio Code

Щоб почати використовувати VSC:

- **Завантаження та встановлення**: перейдіть на [сайт Visual Studio Code](https://code.visualstudio.com/) і завантажте версію для Linux.

- **Ознайомлення з інтерфейсом**: зліва — **панель активності** для навігації між файлами, пошуку, Git і розширень.

- **Відкриття файлу або папки**: налаштуйте робочу область, додавши папку проєкту, і збережіть конфігурацію у файлі робочої області.

Робоча область — це збережений перегляд папки та налаштувань редактора для вашого проєкту.

### Розширення

- **Встановлення розширень**: клацніть піктограму **Розширення** на панелі активності, щоб знайти корисні інструменти для Scheme. Основне розширення — **«vscode-scheme»** від Allen Huang: воно дає підсвічування синтаксису та базову підтримку Scheme.

Також можна налаштувати розширення, відредагувавши мовний файл і додавши ключові слова, специфічні для Scheme, або для скриптів Lumi.

Якщо ви підтримуєте власну допоміжну бібліотеку, додавання імен функцій проєкту до підсвічування синтаксису пришвидшує навігацію та рефакторинг.

### Висновок

Обирайте редактор, який полегшує пошук, рефакторинг і швидке редагування. VS Code з розширенням для Scheme — надійна основа.

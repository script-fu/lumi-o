## Що таке Cursor?

[Cursor](https://cursor.com/) — редактор коду з допомогою ШІ в тому самому вікні. Він ґрунтується на Visual Studio Code, тож підсвічування синтаксису, розширення, робочі області й Git лишаються. Cursor — редактор, яким тут користуються для скриптів Lumi, бо ця допомога ШІ значно дешевша.

- **Підсвічування синтаксису**: Підсвічування розфарбовує код. Помилки помітніші, структура зрозуміліша, складний код читається легше.
- **Розширення**: Cursor запускає розширення Visual Studio Code. Мова, тема чи інструмент: знайдеться відповідне розширення.
- **Інтеграція контролю версій**: Git вбудовано. Зміни легко відстежувати, гілки — вести, користуючись сервісами на кшталт [GitHub](https://github.com/) чи [GitLab](https://gitlab.com/).
- **ШІ в редакторі**: Можна попросити пошук, рефакторинг або невелику правку поруч із уже відкритим файлом. Вартість цієї допомоги досить низька, щоб користуватися нею в звичайній роботі над скриптами.

### Основні можливості для початківців

- **Робочі області**: Cursor збирає кілька проєктів у «робочі області», де пов’язані файли й теки лежать разом. Навігація й ведення проєкту стають простішими.

- **Профілі**: Профілі дають змогу мати різні набори для проєктів або завдань. Один для веброзробки, інший для Scheme, у кожного свої розширення, теми й параметри.

### Початок роботи з Cursor

Щоб почати користуватися Cursor:

- **Завантажте й установіть**: Відкрийте [сайт Cursor](https://cursor.com/) і завантажте версію для Linux.

- **Огляньте інтерфейс**: Відкривши Cursor, ви побачите кілька панелей. Ліворуч — **панель дій**, звідки переходять до файлів, пошуку, Git і розширень.

- **Відкрийте файл або теку**: Налаштуйте робочу область, додавши теку проєкту, і збережіть поточну конфігурацію у файл робочої області.

Робоча область — це збережений вигляд теки плюс параметри редактора для проєкту.

### Розширення

- **Установіть розширення**: Натисніть піктограму **Розширення** на панелі дій, щоб знайти й установити корисні засоби для Scheme. Головне — **«vscode-scheme»** Аллена Хуанга. Воно дає підсвічування синтаксису й базову підтримку Scheme, мови, якою пишуть плагіни Lumi.

Розширення можна налаштувати, правлячи файл мови й додаючи нові ключові слова Scheme або терміни скриптів Lumi.

Якщо ви ведете власну допоміжну бібліотеку, додавання імен функцій до підсвічування пришвидшує навігацію й рефакторинг.

### Висновок

Користуйтеся редактором, у якому легко шукати, перебудовувати код і вносити дрібні правки, а ШІ поруч. Cursor разом із розширенням Scheme — основа, якою користуються тут.

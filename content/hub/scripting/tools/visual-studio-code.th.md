## Cursor คืออะไร

[Cursor](https://cursor.com/) เป็นตัวแก้ไขโค้ดที่มีความช่วยเหลือจาก AI ในหน้าต่างเดียวกัน มันสร้างบน Visual Studio Code ดังนั้นการเน้นไวยากรณ์ ส่วนขยาย พื้นที่ทำงาน และ Git ยังอยู่ครบ Cursor เป็นตัวแก้ไขที่ใช้ที่นี่สำหรับสคริปต์ Lumi เพราะความช่วยเหลือจาก AI นั้นประหยัดกว่ามาก

- **การเน้นไวยากรณ์**: การเน้นใส่สีให้โค้ด ข้อผิดพลาดเห็นได้เร็วขึ้น โครงสร้างอ่านง่าย และโค้ดที่ซับซ้อนตามได้ชัดขึ้น
- **ส่วนขยาย**: Cursor เรียกใช้ส่วนขยายของ Visual Studio Code ไม่ว่าจะเป็นภาษา ธีม หรือเครื่องมือ ก็มีส่วนขยายที่เหมาะ
- **การรวมการควบคุมเวอร์ชัน**: Git มากับโปรแกรม การติดตามการเปลี่ยนแปลงและการดูแลสาขาทำได้ง่าย ด้วยบริการอย่าง [GitHub](https://github.com/) หรือ [GitLab](https://gitlab.com/)
- **AI ในตัวแก้ไข**: ขอให้ค้นหา ปรับโครงสร้าง หรือแก้เล็กน้อยข้างไฟล์ที่เปิดอยู่ได้ ค่าใช้จ่ายของความช่วยเหลือนี้ต่ำพอจะใช้ในงานสคริปต์ประจำวัน

### คุณสมบัติสำคัญสำหรับผู้เริ่มต้น

- **พื้นที่ทำงาน**: Cursor จัดหลายโปรเจกต์เป็น "พื้นที่ทำงาน" ซึ่งเก็บไฟล์และโฟลเดอร์ที่เกี่ยวข้องไว้ด้วยกัน การนำทางและการดูแลโปรเจกต์ง่ายขึ้น

- **โปรไฟล์**: โปรไฟล์ให้เตรียมชุดการตั้งค่าต่างกันตามโปรเจกต์หรืองาน ชุดหนึ่งสำหรับพัฒนาเว็บ อีกชุดสำหรับ Scheme แต่ละชุดมีส่วนขยาย ธีม และการตั้งค่าของตนเอง

### เริ่มใช้ Cursor

การเริ่มใช้ Cursor:

- **ดาวน์โหลดและติดตั้ง**: ไปที่ [เว็บไซต์ Cursor](https://cursor.com/) แล้วดาวน์โหลดรุ่นสำหรับลินุกซ์

- **สำรวจหน้าตา**: เมื่อเปิด Cursor จะเห็นแผงหลายแผง ทางซ้ายคือ **แถบกิจกรรม** ซึ่งใช้สลับระหว่างไฟล์ การค้นหา Git และส่วนขยาย

- **เปิดไฟล์หรือโฟลเดอร์**: ตั้งพื้นที่ทำงานโดยเพิ่มโฟลเดอร์ของโปรเจกต์ แล้วบันทึกการตั้งค่าที่ใช้อยู่เป็นไฟล์พื้นที่ทำงาน

พื้นที่ทำงานเป็นเพียงมุมมองโฟลเดอร์ที่บันทึกไว้ พร้อมการตั้งค่าตัวแก้ไขของโปรเจกต์นั้น

### ส่วนขยาย

- **ติดตั้งส่วนขยาย**: คลิกไอคอน **ส่วนขยาย** บนแถบกิจกรรม เพื่อค้นหาและติดตั้งเครื่องมือที่เป็นประโยชน์กับ Scheme ตัวหลักคือ **"vscode-scheme"** ของ Allen Huang ให้การเน้นไวยากรณ์และการรองรับพื้นฐานสำหรับ Scheme ซึ่งเป็นภาษาที่ใช้เขียนปลั๊กอินของ Lumi

ปรับส่วนขยายได้ด้วยการแก้ไฟล์ภาษา เพื่อเพิ่มคำสำคัญของ Scheme หรือคำที่เกี่ยวกับสคริปต์ Lumi

ถ้าคุณดูแลไลบรารีช่วยเหลือของตนเอง การใส่ชื่อฟังก์ชันเข้าไปในการเน้นทำให้การนำทางและการปรับโครงสร้างเร็วขึ้น

### สรุป

ใช้ตัวแก้ไขที่ทำให้ค้นหา ปรับโครงสร้าง และแก้เร็วได้สะดวก โดยมี AI อยู่ใกล้มือ Cursor พร้อมส่วนขยาย Scheme เป็นฐานที่ใช้ที่นี่

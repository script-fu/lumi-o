## ما هو Cursor؟

[Cursor](https://cursor.com/) محرّر شيفرة مع مساعدة من الذكاء الاصطناعي في النافذة نفسها. يقوم على Visual Studio Code، فتبقى إضاءة البنية والامتدادات ومساحات العمل وGit. Cursor هو المحرّر المستخدم هنا لسكربتات Lumi، لأن مساعدة الذكاء الاصطناعي هذه أوفر بكثير.

- **إضاءة البنية**: تلوّن الإضاءة الشيفرة. تظهر الأخطاء أبكر، وتتضح البنية، وتُقرأ الشيفرة المعقّدة بأيسر.
- **الامتدادات**: يشغّل Cursor امتدادات Visual Studio Code. لغة أو سمة أو أداة: يوجد امتداد يناسب.
- **تكامل التحكم في الإصدارات**: Git مدمج. يسهل تتبّع التغييرات وإدارة الفروع، بخدمات مثل [GitHub](https://github.com/) أو [GitLab](https://gitlab.com/).
- **الذكاء الاصطناعي في المحرّر**: يمكن طلب بحث أو إعادة هيكلة أو تعديل صغير إلى جانب الملف المفتوح. تكلفة هذه المساعدة منخفضة بما يكفي لاستعمالها في كتابة السكربتات المعتادة.

### ميزات أساسية للمبتدئين

- **مساحات العمل**: يرتّب Cursor عدة مشاريع في «مساحات عمل» تُبقي الملفات والمجلدات المرتبطة معًا. يصبح التنقل وإدارة المشروع أيسر.

- **الملفات الشخصية**: تتيح الملفات الشخصية إعدادات مختلفة للمشاريع أو المهام. واحد لتطوير الويب وآخر لـ Scheme، ولكل منهما امتداداته وسماته وإعداداته.

### البدء مع Cursor

للبدء باستخدام Cursor:

- **التنزيل والتثبيت**: اذهب إلى [موقع Cursor](https://cursor.com/) ونزّل نسخة لينكس.

- **استكشاف الواجهة**: عند فتح Cursor تظهر عدة لوحات. على اليسار **شريط النشاط**، ومنه تنتقل بين الملفات والبحث وGit والامتدادات.

- **فتح ملف أو مجلد**: جهّز مساحة العمل بإضافة مجلد المشروع، واحفظ التكوين النشط في ملف مساحة عمل.

مساحة العمل مجرد عرض محفوظ لمجلد، مع إعدادات المحرّر لذلك المشروع.

### الامتدادات

- **تثبيت الامتدادات**: انقر أيقونة **الامتدادات** في شريط النشاط لتتصفح وتثبّت أدوات مفيدة لـ Scheme. الأساس هو **«vscode-scheme»** من Allen Huang. يوفّر إضاءة البنية ودعمًا أساسيًا لـ Scheme، اللغة التي تُكتب بها إضافات Lumi.

يمكن أيضًا تكييف الامتداد بتحرير ملف اللغة لإضافة كلمات مفتاحية أخرى من Scheme أو ما يتصل بسكربتات Lumi.

إذا كنت تصون مكتبة مساعدة خاصة بك، فإن إضافة أسماء الدوال إلى الإضاءة تجعل التنقل وإعادة الهيكلة أسرع.

### الخلاصة

استخدم محرّرًا يسهّل البحث وإعادة الهيكلة والتعديلات السريعة، والذكاء الاصطناعي في المتناول. Cursor مع امتداد Scheme هو الأساس المستخدم هنا.

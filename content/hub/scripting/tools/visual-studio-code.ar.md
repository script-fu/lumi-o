## ما هو Visual Studio Code؟

[Visual Studio Code](https://code.visualstudio.com/) (يُختصر غالبًا إلى «VS Code» أو «VSC») محرّر نصوص مجاني ومفتوح المصدر من Microsoft، مصمّم خصيصًا للبرمجة. إنه خفيف وسريع وقابل للتخصيص بدرجة كبيرة، ما جعله من أكثر محرّرات التعليمات البرمجية شيوعًا بين المطوّرين. إليك سبب كون VSC خيارًا ممتازًا:

- **تمييز بناء الجملة**: يُلوّن التعليمات البرمجية بألوان مميّزة، فيسهل اكتشاف الأخطاء وفهم البنية وقراءة التعليمات المعقّدة.
- **الامتدادات**: يمكنك تحسين VSC بآلاف الامتدادات. سواء احتجت دعمًا للغة أو سمة أو أداة معيّنة، ستجد امتدادًا يناسبك.
- **تكامل التحكم في الإصدارات**: يتضمّن VSC دعم Git مدمجًا، فيسهل تتبّع التغييرات وإدارة الفروع باستخدام خدمات مثل [GitHub](https://github.com/) أو [GitLab](https://gitlab.com/).

### ميزات أساسية للمبتدئين

- **مساحات العمل**: يتيح لك VSC تنظيم مشاريع متعددة في «مساحات عمل»، بحيث تبقى الملفات والمجلدات ذات الصلة معًا لتسهيل التنقّل وإدارة المشروع.

- **الملفات الشخصية**: باستخدام الملفات الشخصية، يمكنك إنشاء إعدادات مختلفة لمشاريع أو مهام مختلفة. قد تستخدم ملفًا شخصيًا لتطوير الويب وآخر لبرمجة Scheme، ولكل منهما امتداداته وسماته وإعداداته.

### البدء مع Visual Studio Code

لبدء استخدام VSC:

- **التنزيل والتثبيت**: انتقل إلى [موقع Visual Studio Code](https://code.visualstudio.com/) ونزّل إصدار Linux.

- **استكشاف الواجهة**: عند فتح VSC، ستلاحظ عدة لوحات. على اليسار يوجد **شريط الأنشطة**، حيث تتنقّل بين الملفات والبحث وGit وتثبيت الامتدادات.

- **فتح ملف أو مجلد**: أعد مساحة عملك بإضافة المجلد الذي يُخزَّن فيه مشروعك، واحفظ الإعداد النشط في ملف مساحة عمل.

مساحة العمل هي مجرد عرض محفوظ للمجلد مع إعدادات المحرّر لمشروعك.

### الامتدادات

- **تثبيت الامتدادات**: انقر أيقونة **Extensions** في شريط الأنشطة لتصفّح وتثبيت أدوات مفيدة لـ Scheme. أهم امتداد للتثبيت هو **«vscode-scheme»** من Allen Huang. يوفّر هذا الامتداد تمييز بناء الجملة ودعمًا أساسيًا لـ Scheme، وهي اللغة الأساسية لبرمجة Lumi.

يمكنك أيضًا تخصيص الامتداد بتحرير ملف اللغة ليشمل مزيدًا من الكلمات المفتاحية الخاصة بـ Scheme أو أي شيء متعلق ببرمجة Lumi.

إذا حافظت على مكتبة مساعدة خاصة، فإضافة أسماء دوال مشروعك إلى مُميّز بناء الجملة تُسرّع التنقّل وإعادة الهيكلة.

### الخلاصة

استخدم محرّرًا يسهّل البحث وإعادة الهيكلة والتعديلات السريعة. VS Code مع امتداد Scheme خط أساس متين.

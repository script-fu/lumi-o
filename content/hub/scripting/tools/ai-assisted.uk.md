Сучасні інструменти штучного інтелекту можуть значно прискорити розробку плагінів Lumi, виступаючи партнером зі спільного написання коду.

## VS Code у режимі агента

Visual Studio Code з ШІ-помічником у **режимі агента** (наприклад, GitHub Copilot Agent або інші помічники з підтримкою інструментів) дозволяє виконувати складні багатоетапні завдання природною мовою.

Замість автодоповнення одного рядка агент може:

- прочитати всю робочу область, щоб зрозуміти контекст;
- створити нові файли та каталоги;
- виконати команди терміналу для тестування або перевірки скриптів;
- знайти існуючі шаблони у вашій кодовій базі.

## Доступ до репозиторію

ШІ найефективніший, коли агент має доступ до **lumi-dev** або репозиторію вашого проєкту. Маючи доступ до наявного коду, агент може:

- використовувати **[бібліотеки утиліт]({{< ref "/hub/scripting/reference/utility-browser" >}})** як довідник допоміжних функцій;
- дотримуватися існуючих шаблонів для операцій GEGL і керування шарами;
- повторно використовувати шаблонний код зі встановлених плагінів.

## Приклад робочого процесу

Можна попросити агента створити повний плагін, описавши бажаний результат:

> «Використовуючи доступні утиліти Scheme та приклади в робочій області, напиши новий модуль, який створює горизонтальну напрямну на 50% активного зображення та називає її „Central Guide“.»

Агент знайде, як створювати напрямні, визначить правильну утиліту (наприклад, `lumi-image-add-hguide-percent` з `common.scm`) і згенерує повний файл `.scm` із коректною реєстрацією плагіна.

## Найкращі практики

- **Будьте конкретними**: опишіть, що саме має робити плагін.
- **Посилання на утиліти**: попросіть агента переглянути каталог `share/lumi/scripts/` для високорівневих помічників.
- **Перегляд і тестування**: завжди перевіряйте згенерований ШІ плагін — це часто ітеративний і творчий процес.

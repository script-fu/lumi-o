## Что такое Cursor?

[Cursor](https://cursor.com/) — редактор кода с помощью ИИ в том же окне. Он основан на Visual Studio Code, поэтому подсветка синтаксиса, расширения, рабочие области и Git сохраняются. Cursor — редактор, которым здесь пользуются для скриптов Lumi, потому что эта помощь ИИ заметно дешевле.

- **Подсветка синтаксиса**: Подсветка раскрашивает код. Ошибки заметнее, структура понятнее, сложный код читается легче.
- **Расширения**: Cursor запускает расширения Visual Studio Code. Язык, тема или инструмент: найдётся подходящее расширение.
- **Интеграция контроля версий**: Git встроен. Изменения легко отслеживать, ветки — вести, пользуясь сервисами вроде [GitHub](https://github.com/) или [GitLab](https://gitlab.com/).
- **ИИ в редакторе**: Можно попросить поиск, рефакторинг или небольшую правку рядом с уже открытым файлом. Стоимость этой помощи достаточно низкая, чтобы пользоваться ею в обычной работе над скриптами.

### Основные возможности для начинающих

- **Рабочие области**: Cursor собирает несколько проектов в «рабочие области», где связанные файлы и папки лежат вместе. Навигация и ведение проекта становятся проще.

- **Профили**: Профили позволяют завести разные наборы для проектов или задач. Один для веб-разработки, другой для Scheme, у каждого свои расширения, темы и настройки.

### Начало работы с Cursor

Чтобы начать пользоваться Cursor:

- **Скачайте и установите**: Откройте [сайт Cursor](https://cursor.com/) и скачайте версию для Linux.

- **Изучите интерфейс**: Открыв Cursor, вы увидите несколько панелей. Слева — **панель действий**, откуда переходят к файлам, поиску, Git и расширениям.

- **Откройте файл или папку**: Настройте рабочую область, добавив папку проекта, и сохраните текущую конфигурацию в файл рабочей области.

Рабочая область — это сохранённый вид папки плюс настройки редактора для проекта.

### Расширения

- **Установите расширения**: Нажмите значок **Расширения** на панели действий, чтобы найти и установить полезные средства для Scheme. Главное — **«vscode-scheme»** Аллена Хуанга. Оно даёт подсветку синтаксиса и базовую поддержку Scheme, языка, на котором пишут подключаемые модули Lumi.

Расширение можно настроить, правя файл языка и добавляя новые ключевые слова Scheme или термины скриптов Lumi.

Если вы ведёте собственную вспомогательную библиотеку, добавление имён функций в подсветку ускоряет навигацию и рефакторинг.

### Заключение

Пользуйтесь редактором, в котором легко искать, перестраивать код и вносить мелкие правки, а ИИ рядом. Cursor вместе с расширением Scheme — основа, которой пользуются здесь.

## Cursor とは

[Cursor](https://cursor.com/) は、同じウィンドウで AI の手助けが得られるコードエディターです。Visual Studio Code を土台にしているので、構文の色分け、拡張機能、ワークスペース、Git はそのまま使えます。Lumi のスクリプトにはここで Cursor を使います。その AI の手助けがずっと経済的だからです。

- **構文の色分け**: 色分けはコードに色を付けます。誤りに気づきやすく、構造が読み取れ、複雑なコードも追いやすくなります。
- **拡張機能**: Cursor は Visual Studio Code の拡張機能を動かします。言語、テーマ、道具のどれであっても、合う拡張機能があります。
- **バージョン管理**: Git が組み込まれています。変更の追跡やブランチの管理が、[GitHub](https://github.com/) や [GitLab](https://gitlab.com/) のようなサービスとともに容易になります。
- **エディターの中の AI**: すでに開いているファイルのそばで、検索、リファクタ、小さな修正を頼めます。その手助けの費用は、普段のスクリプト作業に使えるほど低く抑えられています。

### 初めて使うときの主な機能

- **ワークスペース**: Cursor は複数のプロジェクトを「ワークスペース」にまとめ、関連するファイルとフォルダーを一緒に置けます。移動とプロジェクトの管理が楽になります。

- **プロファイル**: プロファイルで、プロジェクトや作業ごとに別の構成を用意できます。ウェブ開発用と Scheme 用を分け、それぞれに拡張機能、テーマ、設定を持たせられます。

### Cursor を始める

Cursor を使い始めるには:

- **ダウンロードしてインストール**: [Cursor のサイト](https://cursor.com/) を開き、Linux 版を入手します。

- **画面を見る**: Cursor を開くと、いくつかのパネルがあります。左の **アクティビティバー** から、ファイル、検索、Git、拡張機能を行き来します。

- **ファイルまたはフォルダーを開く**: プロジェクトのフォルダーを加えてワークスペースを用意し、今の構成をワークスペースファイルに保存します。

ワークスペースは、保存したフォルダーの見え方に、そのプロジェクトのエディター設定を足したものです。

### 拡張機能

- **拡張機能を入れる**: アクティビティバーの **拡張機能** アイコンをクリックし、Scheme に役立つ道具を探して入れます。中心になるのは Allen Huang の **「vscode-scheme」** です。構文の色分けと、Lumi のプラグインを書く言語である Scheme の基本的な支援を提供します。

言語ファイルを編集して、Scheme のキーワードや Lumi のスクリプトに関する語を足し、拡張機能を自分向けにすることもできます。

自分の補助ライブラリを手入れしているなら、関数名を色分けに加えると、移動とリファクタが速くなります。

### まとめ

検索、リファクタ、ちょっとした修正がしやすく、AI が手の届くところにあるエディターを使ってください。Cursor と Scheme の拡張機能が、ここで使う基本です。

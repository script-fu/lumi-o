중요한 파일을 백업해 이전 버전으로 되돌리거나 손상된 데이터를 교체하는 것은 흔합니다. 하지만 또 하나 중요한 백업 유형은 시스템 상태 전체를 저장하는 **디스크 복제**입니다.

시스템을 구성해 안정적으로 동작하게 되면, 재해 발생 시 환경을 복원할 수 있도록 전체 백업을 만드는 것이 중요합니다. 이는 작업 데이터를 정기적으로 저장하는 습관을 보완합니다.

[Clonezilla](https://clonezilla.org/)는 무료 오픈 소스 디스크 이미징 및 복제 소프트웨어입니다. 컴퓨터 하드 드라이브 전체 백업을 만들고 복원할 수 있어 IT 전문가와 가정 사용자 모두에게 널리 쓰입니다.

백업이 필요 없을 때도 갖고 있는 편이, 필요한데 없는 것보다 낫습니다.

## Clonezilla의 주요 기능

- **디스크 이미징**: Clonezilla는 운영 체제, 애플리케이션, 데이터를 포함한 하드 드라이브의 정확한 복사본을 만듭니다.
- **백업 및 복원**: 하드 드라이브 백업 이미지를 만들고, 장애나 새 드라이브로의 이전 시 복원할 수 있습니다.
- **무료 오픈 소스**: Clonezilla는 완전 무료이며, 소스 코드를 수정하고 맞춤 설정할 수 있습니다.

## Clonezilla로 백업하기

### 준비

Clonezilla용 USB 드라이브와, 복제할 내장 드라이브보다 큰 외장 하드 드라이브가 필요합니다.

아래 단계는 [공식 가이드](https://clonezilla.org//fine-print-live-doc.php?path=./clonezilla-live/doc/01_Save_disk_image/00-boot-clonezilla-live-cd.doc#00-boot-clonezilla-live-cd.doc)를 간소화한 것입니다. 스크린샷이 포함된 전체 가이드도 함께 확인하는 것이 좋습니다.

1. **Clonezilla Live USB 또는 CD/DVD 만들기**: Clonezilla [웹사이트](https://clonezilla.org/liveusb.php)의 안내에 따라 부팅 가능한 USB 또는 CD/DVD를 만듭니다.

2. **외장 백업 드라이브 연결**: 외장 드라이브를 연결하고 시스템이 인식하는지 확인합니다. 백업 저장 대상이 됩니다.

3. **파티션 레이아웃 확인**: 터미널에서 `lsblk`로 기본 하드 드라이브의 파티션 레이아웃을 확인합니다. 기본 장치 이름을 기록해 둡니다.

4. **Clonezilla Live USB에서 부팅**: 컴퓨터를 재시작하고 만든 Clonezilla 미디어에서 부팅합니다. BIOS/UEFI 설정(보통 부팅 중 F2, F12, Esc, Del)에서 USB를 우선 부팅하도록 변경해야 할 수 있습니다.

### Clonezilla 백업 절차

1. **백업 모드 선택**: Clonezilla가 부팅되면 "device-device" 모드를 선택합니다. 내장 드라이브를 외장 장치로 직접 복제할 수 있습니다.

2. **소스 장치 선택**: 기본 내장 드라이브를 선택합니다.

3. **대상 장치 선택**: 외장 백업 드라이브를 대상으로 선택합니다. 중요한 데이터를 덮어쓰지 않도록 주의하세요. 대상 드라이브는 소스와 같거나 더 커야 합니다.

4. **백업 시작**: Clonezilla가 백업을 시작합니다. 파티션 크기와 드라이브 속도에 따라 수분에서 수시간이 걸릴 수 있습니다.

5. **백업에 라벨 붙이기**: 완료 후 USB 드라이브와 외장 하드 드라이브에 날짜와 백업한 시스템을 표시하고 안전한 곳에 보관합니다.

---

### 백업에서 복원

Debian 시스템을 백업에서 복원해야 한다면:

1. **Clonezilla 미디어에서 부팅**: Clonezilla USB를 연결하고 백업 때와 같은 방법으로 부팅합니다.

2. **복원 모드 선택**: 다시 "device-device" 모드를 선택하되, 이번에는 백업 이미지에서 복원합니다. 외장 드라이브의 데이터가 내장 드라이브로 복사됩니다.

3. **소스 장치 선택**: 백업이 저장된 외장 드라이브를 선택합니다.

4. **대상 장치 선택**: 복원할 내장 드라이브를 선택합니다.

5. **복원 시작**: Clonezilla가 복원을 시작합니다. 소요 시간은 백업 때와 같이 드라이브 크기와 하드웨어 속도에 따라 달라집니다.

## 마무리

Clonezilla 디스크 백업은 운영 체제, 설정, 애플리케이션을 포함한 시스템 전체를 보존합니다. 최소한의 노력으로 치명적 장애로부터 시스템을 보호하고, 충돌 시 다운타임을 줄일 수 있습니다.

**백업은 필수**입니다. 정기적으로 갱신하고, 필요할 때 복원할 수 있는지 주기적으로 확인하세요.

부팅 후 외장 백업 드라이브를 연결하고 Linux의 Disks 유틸리티로 파티션 구조를 확인할 수 있습니다. 백업 드라이브는 내부 드라이브와 같은 파티션 구조를 반영해야 하며, 외장 드라이브가 더 크면 미사용 공간이 남습니다.

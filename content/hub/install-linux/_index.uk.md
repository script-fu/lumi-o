Ласкаво просимо до посібників із встановлення Linux для Lumi.

У цих посібниках описано налаштування операційної системи, яке використовується для розробки та тестування Lumi. Вони призначені для художників і розробників, які хочуть стабільне, відтворюване середовище Linux, а не налаштовану під себе чи експериментальну конфігурацію.

Основна увага приділяється системам на базі Debian, обраним за надійність і довгострокову послідовність. Кожен посібник містить практичний покроковий підхід, який допомагає перейти від існуючої системи до перевіреного робочого налаштування з мінімальною невизначеністю.

Теми включають встановлення Debian, налаштування системи та резервне копіювання.

Bem-vindo aos guias de instalação do Linux para Lumi.

Estes guias documentam a configuração do sistema operacional usada para o desenvolvimento e os testes do Lumi. Eles são destinados a artistas e desenvolvedores que desejam um ambiente Linux estável e reproduzível, em vez de uma configuração personalizada ou experimental.

O foco está em sistemas baseados em Debian, escolhidos pela confiabilidade e consistência de longo prazo. Cada guia segue uma abordagem prática passo a passo para ajudar você a passar de um sistema existente para uma configuração conhecida e funcional com o mínimo de incerteza.

Os tópicos incluem instalação do Debian, configuração do sistema e backups.

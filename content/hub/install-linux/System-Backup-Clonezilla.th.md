เป็นเรื่องปกติที่จะสำรองไฟล์สำคัญเพื่อกลับไปใช้เวอร์ชันก่อนหน้าหรือแทนที่ข้อมูลที่เสียหาย แต่การสำรองข้อมูลอีกประเภทที่สำคัญคือ **การโคลนดิสก์** ซึ่งเป็นการสำรองสถานะของระบบทั้งหมด

เมื่อตั้งค่าระบบและใช้งานได้ดีแล้ว การสำรองข้อมูลแบบเต็มมีความสำคัญต่อการกู้คืนสภาพแวดล้อมหากเกิดปัญหาร้ายแรง การสำรองนี้เสริมการบันทึกข้อมูลงานเป็นประจำ

[Clonezilla](https://clonezilla.org/) เป็นซอฟต์แวร์สร้างภาพและโคลนดิสก์แบบโอเพ่นซอร์สฟรี ช่วยให้ผู้ใช้สร้างและกู้คืนข้อมูลสำรองทั้งดิสก์ได้ — เป็นเครื่องมือยอดนิยมทั้งสำหรับผู้เชี่ยวชาญด้าน IT และผู้ใช้ทั่วไป

การมีข้อมูลสำรองแต่ไม่ต้องใช้ ย่อมดีกว่าการต้องมีแต่ไม่มี


## คุณสมบัติสำคัญของ Clonezilla

- **การสร้างภาพดิสก์**: Clonezilla สร้างสำเนาฮาร์ดไดรฟ์ที่เหมือนต้นฉบับ รวมระบบปฏิบัติการ แอปพลิเคชัน และข้อมูล
- **สำรองและกู้คืน**: สร้างอิมเมจสำรองของดิสก์และกู้คืนเมื่อเกิดความล้มเหลวหรือย้ายไปดิสก์ใหม่
- **ฟรีและโอเพ่นซอร์ส**: Clonezilla ใช้งานได้ฟรี และมีซอร์สโค้ดให้ปรับแต่งได้


## ใช้ Clonezilla สำรองข้อมูล

### ขั้นตอนเตรียมการ

คุณต้องมีไดรฟ์ USB สำหรับ Clonezilla และฮาร์ดไดรฟ์ภายนอกที่มีขนาดใหญ่กว่าไดรฟ์ภายในที่ต้องการโคลน

ขั้นตอนเหล่านี้ทำให้กระบวนการง่ายขึ้นตาม [คู่มืออย่างเป็นทางการ](https://clonezilla.org//fine-print-live-doc.php?path=./clonezilla-live/doc/01_Save_disk_image/00-boot-clonezilla-live-cd.doc#00-boot-clonezilla-live-cd.doc) ควรอ่านคู่มือฉบับเต็มที่มีภาพหน้าจอประกอบด้วย

1. **สร้าง Clonezilla Live USB หรือ CD/DVD**: ทำตามคำแนะนำบน [เว็บไซต์ Clonezilla](https://clonezilla.org/liveusb.php) เพื่อสร้าง USB หรือ CD/DVD ที่บูตได้

2. **เชื่อมต่อไดรฟ์สำรองภายนอก**: เสียบไดรฟ์ภายนอกและตรวจสอบว่าระบบรู้จัก นี่คือปลายทางของการสำรองข้อมูล

3. **ตรวจสอบเลย์เอาต์พาร์ติชัน**: ใช้คำสั่ง `lsblk` ในเทอร์มินัลเพื่อตรวจสอบเลย์เอาต์ของฮาร์ดไดรฟ์หลัก จดชื่ออุปกรณ์หลัก

4. **บูตจาก Clonezilla Live USB**: รีสตาร์ทและบูตจากสื่อ Clonezilla ที่สร้างไว้ อาจต้องเข้า BIOS/UEFI (มักกด F2, F12, ESC หรือ DEL ระหว่างบูต) และตั้งลำดับการบูตให้ USB มาก่อน



### สำรองข้อมูลด้วย Clonezilla

1. **เลือกโหมดสำรองข้อมูล**: เมื่อ Clonezilla บูตแล้ว เลือกโหมด "device-device" โหมดนี้โคลนไดรฟ์ภายในไปยังอุปกรณ์ภายนอกโดยตรง

2. **เลือกอุปกรณ์ต้นทาง**: เลือกไดรฟ์ภายในหลัก

3. **เลือกอุปกรณ์ปลายทาง**: เลือกไดรฟ์สำรองภายนอกเป็นปลายทาง ระวังอย่าเลือกผิดและเขียนทับข้อมูลสำคัญ ไดรฟ์ปลายทางต้องมีขนาดเท่ากับหรือใหญ่กว่าไดรฟ์ต้นทาง

4. **เริ่มกระบวนการสำรอง**: Clonezilla จะเริ่มสำรอง อาจใช้เวลาตั้งแต่ไม่กี่นาทีถึงหลายชั่วโมง ขึ้นกับขนาดพาร์ติชันและความเร็วดิสก์

5. **ติดป้ายกำกับการสำรอง**: เมื่อเสร็จแล้ว ติดป้าย USB และฮาร์ดไดรฟ์ภายนอกพร้อมวันที่และชื่อระบบที่สำรอง เก็บไว้ในที่ปลอดภัย

---

### กู้คืนจากข้อมูลสำรอง

หากต้องกู้คืนระบบ Debian จากข้อมูลสำรอง ให้ทำตามขั้นตอนเหล่านี้:

1. **บูตจากสื่อ Clonezilla**: ใส่ USB Clonezilla และบูตจาก USB ด้วยขั้นตอนเดียวกับตอนสำรอง

2. **เลือกโหมดกู้คืน**: เลือกโหมด "device-device" อีกครั้ง แต่คราวนี้กู้คืนจากอิมเมจสำรอง ข้อมูลทั้งหมดจะถูกคัดลอกจากไดรฟ์ภายนอกกลับไปยังไดรฟ์ภายใน

3. **เลือกอุปกรณ์ต้นทาง**: เลือกไดรฟ์ภายนอกที่เก็บข้อมูลสำรอง

4. **เลือกอุปกรณ์ปลายทาง**: เลือกไดรฟ์ภายในที่ต้องการกู้คืน

5. **เริ่มกระบวนการกู้คืน**: Clonezilla จะเริ่มกู้คืน เวลาที่ใช้ขึ้นกับขนาดดิสก์และความเร็วฮาร์ดแวร์ เช่นเดียวกับตอนสำรอง

## หมายเหตุสุดท้าย

การสำรองดิสก์ด้วย Clonezilla ช่วยรักษาทั้งระบบ — ระบบปฏิบัติการ การตั้งค่า และแอปพลิเคชัน ด้วยความพยายามเพียงเล็กน้อย คุณปกป้องระบบจากความล้มเหลวร้ายแรงและลดเวลาหยุดทำงานหลังขัดข้อง

โปรดจำไว้ว่า **การสำรองข้อมูลเป็นสิ่งจำเป็น** อัปเดตข้อมูลสำรองเป็นประจำและทดสอบเป็นระยะ เพื่อให้มั่นใจว่ากู้คืนได้เมื่อจำเป็น

หลังบูต คุณสามารถเสียบไดรฟ์สำรองภายนอกและตรวจสอบโครงสร้างพาร์ติชันด้วยยูทิลิตี Disks ใน Linux ไดรฟ์สำรองควรสะท้อนโครงสร้างของไดรฟ์ภายใน มีพาร์ติชันเดียวกัน และอาจมีพื้นที่ว่างหากไดรฟ์ภายนอกใหญ่กว่า

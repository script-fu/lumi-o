يوضّح هذا المستند العملية المستخدمة لتثبيت Debian Stable كنظام تشغيل تطوير Lumi-o. قد يفيد من يريد إعداد بيئة مماثلة.

اختير Debian Stable لأن Lumi يهدف إلى البناء بموثوقية على منصة طويلة الأمد ويمكن التنبؤ بها. يستهدف تطوير GIMP Debian Testing، ما يجعل Debian Stable نظامًا أساسيًا متوافقًا بشكل وثيق.

Lumi في أفضل حالاته على Debian مع Cinnamon (X11)، ويُطوَّر ويُختبَر في هذه البيئة. يوفّر Cinnamon سير عمل سطح مكتب مألوفًا يشبه Windows، بينما يوفّر X11 البيئة الأكثر استقرارًا لتطوير Lumi.

إذا كنت قادمًا من Windows، فإن التغيير المفاهيمي الرئيسي هو أن معظم تثبيت البرامج وتكوينها يتم عبر مديري الحزم وأوامر طرفية بسيطة، وليس عبر مثبّتات قابلة للتنزيل.

## لمن هذا الدليل

يوثّق هذا الدليل إعداد Debian Stable العامل المستخدم لتطوير Lumi. ليس درسًا عامًا لتثبيت Linux.

يكون أكثر فائدة لـ:

- الفنانين الذين ينتقلون من Windows ويريدون إعداد Linux يمكن التنبؤ به
- المطورين الذين يبنون Lumi من المصدر
- المستخدمين الذين يفضّلون إعادة إنتاج بيئة عمل معروفة بدلًا من تصميم تكوين نظام خاص بهم

يُفترض معرفة أساسية بتقسيم القرص واستخدام بسيط لسطر الأوامر.

## النسخ الاحتياطي لبياناتك

قبل تثبيت Debian، أنشئ نسخة احتياطية كاملة من مجلد Home على قرص خارجي. ضمّن أي مجلدات بيانات إضافية تريد الاحتفاظ بها.

ملاحظة: في Linux، يمثّل `~` مجلد Home الخاص بك.

إذا كنت تستخدم مستودعات Git، ادفع أي تغييرات مهمة إلى أصولها لتسهيل استعادتها بعد التثبيت. هذه الخطوة ذات صلة فقط إذا كنت تستخدم Git بالفعل.

## إنشاء قسم

أنشئ مساحة على القرص الأساسي لـ Debian. توجد أدلة وأدوات عديدة لهذه الخطوة، منها GParted. حسب إعدادك، قد:

- تصغّر قسم Windows موجودًا للتمهيد المزدوج
- تعيد استخدام قسم Linux موجود
- تُعدّ أقسام Linux وswap جديدة

إذا لم تكن متأكدًا، راجع أدلة خاصة بالجهاز قبل إجراء التغييرات، إذ تختلف خطوات التقسيم بشكل كبير بين الأنظمة.


## إنشاء USB لتثبيت Debian

بافتراض وجود قسم هدف ومساحة swap:

1. نزّل Debian ISO من الموقع الرسمي: https://www.debian.org/
2. على Windows، استخدم BalenaEtcher لكتابة ملف ISO على محرك USB.
3. على Linux، استخدم أداة سطر أوامر مثل `dd` لإنشاء USB قابل للتمهيد.

## تثبيت Debian

1. أدخل محرك USB.
2. أعد التشغيل واضغط مفتاح قائمة التمهيد (غالبًا `F2` أو `F12` أو `Esc` أو `Del`) أثناء الإقلاع.
3. اختر جهاز USB.
4. اختر المثبّت غير الرسومي.
5. اترك كلمة مرور root فارغة عند الطلب حتى يمنح المثبّت صلاحيات sudo لحساب المستخدم.
6. قسّم يدويًا:

   - نظام الملفات: ext4 (مع journaling)
   - Swap: قسم swap موجود
   - نقطة التثبيت: `/`
   - التسمية: `linux`
   - اسم المضيف: اسم النظام الظاهر كـ `user@hostname`
   - حساب المستخدم: اسمك الكامل
   - اسم المستخدم: اسم تسجيل الدخول في الطرفية

7. يعرض مثبّت Debian اختيار بيئة سطح المكتب في هذه المرحلة؛ اختر **Cinnamon** للإعداد الموصى به من Lumi.
8. أكمل التثبيت وأعد التشغيل إلى Debian Stable.

## إعداد النظام

### تحجيم العرض

يتعامل Debian Stable حاليًا مع التحجيم الجزئي بشكل غير متسق، خاصة على شاشات 4K. بدلًا من تقليل دقة العرض، اضبط عناصر الواجهة مباشرة.

التعديلات الموصى بها:

- تجنّب التحجيم الجزئي للعرض.
- القائمة ← اختيار الخط ← إعدادات الخط ← معامل تكبير النص: `2.5`
- خط سطح المكتب: `14`
- اللوحة ← تخصيص ← ارتفاع اللوحة: `60`
- مظهر اللوحة ← حجم أيقونة المنطقة اليمنى الرمزية: `48px`
- الماوس ولوحة اللمس ← ضبط حجم المؤشر
- سطح المكتب (نقر يمين) ← تخصيص ← حجم أيقونة أكبر

تعديل Firefox:

- شريط العناوين ← `about:config`
- اضبط `layout.css.devPixelsPerPx` على `1`

### الطرفية

اضبط تفضيلات الطرفية:

1. القائمة ← Terminal ← Edit ← Preferences
2. Text ← Initial size: `140 columns`، `40 rows`
3. Text ← Custom font: `Monospace 10`
4. Colours ← Built-in schemes ← Solarized Dark

### مفتاح Alt لتغيير حجم الأدوات

إذا لم يُغيّر `Alt` + السحب بالنقر الأيمن حجم الفرش في Lumi، فإن سطح المكتب يستخدم Alt لإدارة النوافذ.

1. ابحث في قائمة النظام عن **النوافذ**.
2. النوافذ ← السلوك ← مفتاح خاص لنقل وتغيير حجم النوافذ ← **معطل**

بعد هذا التغيير، يفترض أن يعمل `Alt` + السحب بالنقر الأيمن في Lumi لتغيير حجم الأدوات.

## استعادة البيانات

استعد الملفات المنسوخة احتياطيًا إلى مجلد Home حسب الحاجة، على سبيل المثال:

- `Backup/Home/Artwork` → `~/Artwork`
- `Backup/Home/code` → `~/code`
- `Backup/Home/Desktop` → `~/Desktop`
- `Backup/Home/.ssh` → `~/.ssh`
- `Backup/Home/.config/lumi` → `~/.config/lumi`

ملاحظة: المجلدات التي تبدأ بـ `.` هي أدلة تكوين مخفية في Linux.

## اختياري: إعداد Git

مطلوب فقط إذا كنت تخطط لبناء Lumi أو استعادة المستودعات.

### تثبيت Git

```bash
sudo apt install git
```

اضبط هويتك:

```bash
git config --global --edit
```

#### الوصول إلى GitLab

استعد الوصول إلى المستودعات على GitLab أو GitHub:

1. غيّر أذونات ملف مفتاح SSH: `chmod 600 ~/.ssh/id_rsa`
2. أضف المفتاح إلى تثبيت Git الجديد: `ssh-add ~/.ssh/id_rsa`
3. اختبر الاتصال: `ssh -T git@ssh.gitlab.gnome.org` أو `ssh -T git@github.com`

لكل مستودع، اجلب من الأصل وأعد ضبط الفرع المحلي ليطابقه:

```bash
git reset --hard remote-name/branch-name
git clean -df
```

شغّل `git status` للتأكد من أن المستودعات نظيفة.

أصبح لديك نظام تشغيل جديد مع استعادة البيانات والمستودعات. يعكس هذا الإعداد بيئة عمل معروفة تُستخدم لتطوير Lumi ويمكن تكييفها مع سير العمل الفردي.

## بناء Lumi بعد إعداد نظام التشغيل

توجد سكربتات بناء Lumi في:

`~/code/lumi-dev/build/lumi/scripts`.

```bash
cd ~/code/lumi-dev/build/lumi/scripts

# تثبيت التبعيات مرة واحدة
sudo bash lumi-install-packages.sh

# أول بناء إعداد كامل
bash lumi-build-script.sh --scope setup --dir lumi-dev

# إعادة بناء عادية بعد تغييرات الكود
bash lumi-build-script.sh --scope build --dir lumi-dev

# مسار تجميع سريع
bash lumi-build-script.sh --scope compile --dir lumi-dev

# تشغيل Lumi
bash lumi-launch-active.sh lumi-dev
```

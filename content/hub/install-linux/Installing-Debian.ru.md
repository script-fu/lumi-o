В этом документе описан процесс установки Debian Stable в качестве операционной системы для разработки Lumi-o. Он может быть полезен тем, кто настраивает похожую среду.

Debian Stable выбран потому, что Lumi должен надежно собираться на предсказуемой долгосрочной платформе. Разработка GIMP ориентирована на Debian Testing, поэтому Debian Stable — близко связанная базовая система.

Lumi лучше всего работает на Debian с Cinnamon (X11) и разрабатывается и тестируется в этой среде. Cinnamon обеспечивает привычный рабочий процесс рабочего стола, похожий на Windows, а X11 дает наиболее стабильную среду для разработки Lumi.

Если вы переходите с Windows, главное концептуальное изменение в том, что большая часть установки и настройки программного обеспечения выполняется через менеджеры пакетов и простые команды терминала, а не через загружаемые установщики.

## Для кого это руководство

Это руководство описывает рабочую установку Debian Stable, используемую для разработки Lumi. Это не общее руководство по установке Linux.

Оно наиболее полезно для:

- художников, переходящих с Windows и желающих предсказуемую настройку Linux
- разработчиков, собирающих Lumi из исходников
- пользователей, которые предпочитают воспроизвести известную рабочую среду, а не проектировать собственную конфигурацию системы

Предполагается базовое знакомство с разметкой диска и простым использованием командной строки.

## Сделайте резервную копию данных

Перед установкой Debian создайте полную резервную копию домашнего каталога на внешнем диске. Включите все дополнительные папки с данными, которые нужно сохранить.

Примечание: в Linux `~` обозначает домашний каталог.

Если вы используете репозитории Git, отправьте важные изменения на remotes, чтобы их можно было легко восстановить после установки. Этот шаг актуален только если вы уже используете Git.

## Создайте раздел

Освободите место на основном диске для Debian. Для этого шага существует множество руководств и инструментов, включая GParted. В зависимости от конфигурации вы можете:

- уменьшить существующий раздел Windows для dual boot
- повторно использовать существующий раздел Linux
- подготовить новые разделы Linux и swap

Если вы не уверены, перед внесением изменений обратитесь к руководствам для вашего оборудования, поскольку этапы разметки существенно различаются между системами.


## Создайте установочный USB-накопитель Debian

Предполагая, что целевой раздел и пространство swap уже существуют:

1. Загрузите ISO Debian с официального сайта: https://www.debian.org/
2. В Windows используйте BalenaEtcher для записи ISO на USB-накопитель.
3. В Linux используйте инструмент командной строки, например `dd`, чтобы создать загрузочный USB-накопитель.

## Установите Debian

1. Вставьте USB-накопитель.
2. Перезагрузите компьютер и нажмите клавишу меню загрузки (обычно `F2`, `F12`, `Esc` или `Del`) во время запуска.
3. Выберите USB-устройство.
4. Выберите текстовый (неграфический) установщик.
5. Оставьте пароль root пустым, когда появится запрос, чтобы установщик предоставил sudo-доступ вашей учетной записи.
6. Разметьте диск вручную:

   - Файловая система: ext4 (journaling)
   - Swap: существующий раздел swap
   - Точка монтирования: `/`
   - Метка: `linux`
   - Имя хоста: имя системы, отображаемое как `user@hostname`
   - Учетная запись пользователя: ваше полное имя
   - Имя пользователя: имя для входа в терминале

7. На этом этапе установщик Debian предлагает выбрать среду рабочего стола; выберите **Cinnamon** для рекомендуемой конфигурации Lumi.
8. Завершите установку и перезагрузитесь в Debian Stable.

## Настройка системы

### Масштабирование дисплея

Debian Stable сейчас непоследовательно обрабатывает дробное масштабирование, особенно на дисплеях 4K. Вместо снижения разрешения экрана настройте элементы интерфейса напрямую.

Рекомендуемые настройки:

- Избегайте дробного масштабирования экрана.
- Menu → Font Selection → Font Settings → Text Scaling Factor: `2.5`
- Desktop Font: `14`
- Panel → Customize → Panel Height: `60`
- Panel Appearance → Right Zone Symbolic Icon Size: `48px`
- Мышь и сенсорная панель → Размер указателя
- Desktop (right-click) → Customize → Larger icon size

Настройка Firefox:

- Address bar → `about:config`
- Установите для `layout.css.devPixelsPerPx` значение `1`

### Терминал

Настройте параметры терминала:

1. Menu → Terminal → Edit → Preferences
2. Text → Initial size: `140 columns`, `40 rows`
3. Text → Custom font: `Monospace 10`
4. Colours → Built-in schemes → Solarized Dark

### Клавиша Alt для изменения размера инструментов

Если `Alt` + перетаскивание правой кнопкой мыши не изменяет размер кистей в Lumi, рабочий стол использует Alt для управления окнами.

1. Найдите **Окна** в системном меню.
2. Окна → Поведение → Специальная клавиша для перемещения и изменения размеров окон → **Отключено**

После этого изменения `Alt` + перетаскивание правой кнопкой мыши должно работать в Lumi для изменения размера инструментов.

## Восстановите данные

При необходимости восстановите файлы из резервной копии в домашний каталог, например:

- `Backup/Home/Artwork` → `~/Artwork`
- `Backup/Home/code` → `~/code`
- `Backup/Home/Desktop` → `~/Desktop`
- `Backup/Home/.ssh` → `~/.ssh`
- `Backup/Home/.config/lumi` → `~/.config/lumi`

Примечание: папки, начинающиеся с `.`, — это скрытые каталоги конфигурации в Linux.

## Необязательно: настройка Git

Требуется только если вы планируете собирать Lumi или восстанавливать репозитории.

### Установите Git

```bash
sudo apt install git
```

Настройте свою идентификацию:

```bash
git config --global --edit
```

#### Доступ к GitLab

Восстановите доступ к репозиториям в GitLab или GitHub:

1. Измените права доступа к файлу SSH-ключа: `chmod 600 ~/.ssh/id_rsa`
2. Добавьте ключ в ssh-agent: `ssh-add ~/.ssh/id_rsa`
3. Проверьте соединение: `ssh -T git@ssh.gitlab.gnome.org` или `ssh -T git@github.com`

Для каждого репозитория получите изменения с remotes и сбросьте локальную ветку, чтобы она соответствовала:

```bash
git reset --hard remote-name/branch-name
git clean -df
```

Запустите `git status`, чтобы убедиться, что репозитории чисты.

Теперь у вас новая ОС с восстановленными данными и репозиториями. Эта настройка отражает известную рабочую среду для разработки Lumi и при необходимости может быть адаптирована под индивидуальные рабочие процессы.

## Сборка Lumi после настройки ОС

Скрипты сборки Lumi находятся в:

`~/code/lumi-dev/build/lumi/scripts`.

```bash
cd ~/code/lumi-dev/build/lumi/scripts

# Install dependencies once
sudo bash lumi-install-packages.sh

# First full setup build
bash lumi-build-script.sh --scope setup --dir lumi-dev

# Regular rebuild after code changes
bash lumi-build-script.sh --scope build --dir lumi-dev

# Quick compile path
bash lumi-build-script.sh --scope compile --dir lumi-dev

# Launch Lumi
bash lumi-launch-active.sh lumi-dev
```

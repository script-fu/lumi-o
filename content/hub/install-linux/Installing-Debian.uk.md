У цьому документі описано процес встановлення Debian Stable як операційної системи розробки Lumi-o. Це може бути корисним і для інших, хто налаштовує подібне середовище.

Debian Stable обрано тому, що Lumi має надійно збиратися на передбачуваній довгостроковій платформі. Розробка GIMP орієнтована на Debian Testing, тож Debian Stable є близько спорідненою базовою системою.

Lumi найкраще працює на Debian із Cinnamon (X11); саме в цьому середовищі її розробляють і тестують. Cinnamon забезпечує знайомий робочий процес, схожий на Windows, а X11 дає найстабільніше середовище для розробки Lumi.

Якщо ви переходите з Windows, основна концептуальна зміна полягає в тому, що більшість програм встановлюють і налаштовують через менеджери пакетів і прості команди терміналу, а не через завантажувані інсталятори.

## Для кого цей посібник

Цей посібник описує робоче налаштування Debian Stable, яке використовується для розробки Lumi. Це не загальний посібник зі встановлення Linux.

Він найкорисніший для:

- художників, які переходять з Windows і хочуть передбачуваного налаштування Linux
- розробників, які збирають Lumi з вихідного коду
- користувачів, які віддають перевагу відтворенню перевіреного робочого середовища, а не створенню власної конфігурації системи

Передбачається базове знайомство з розміткою диска та простим використанням командного рядка.

## Резервне копіювання даних

Перед встановленням Debian створіть повну резервну копію домашнього каталогу на зовнішньому диску. Додайте будь-які інші папки з даними, які потрібно зберегти.

Примітка: у Linux `~` позначає ваш домашній каталог.

Якщо ви користуєтеся Git-репозиторіями, надішліть важливі зміни до віддалених репозиторіїв, щоб їх можна було легко відновити після встановлення. Цей крок актуальний лише якщо ви вже користуєтеся Git.

## Створення розділу

Звільніть місце на основному диску для Debian. Для цього кроку існує багато посібників і інструментів, зокрема GParted. Залежно від налаштувань можна:

- зменшити існуючий розділ Windows для подвійного завантаження
- повторно використати існуючий розділ Linux
- підготувати нові розділи Linux і підкачки

Якщо ви не впевнені, зверніться до посібників для вашого обладнання перед внесенням змін — кроки розмітки суттєво різняться між системами.


## Створення інсталяційного USB Debian

Припустимо, що цільовий розділ і простір підкачки вже існують:

1. Завантажте ISO Debian з офіційного вебсайту: https://www.debian.org/
2. У Windows скористайтеся BalenaEtcher, щоб записати ISO на USB-накопичувач.
3. У Linux використайте інструмент командного рядка, наприклад `dd`, щоб створити завантажувальний USB.

## Встановлення Debian

1. Вставте USB-накопичувач.
2. Перезавантажте комп’ютер і під час запуску натисніть клавішу меню завантаження (зазвичай `F2`, `F12`, `Esc` або `Del`).
3. Виберіть USB-пристрій.
4. Оберіть неграфічний інсталятор.
5. Залиште пароль root порожнім — тоді інсталятор надасть вашому обліковому запису доступ sudo.
6. Розмітте диск вручну:

   - Файлова система: ext4 (журналювання)
   - Підкачка: існуючий розділ підкачки
   - Точка монтування: `/`
   - Мітка: `linux`
   - Ім’я хоста: назва системи, яка відображається як `user@hostname`
   - Обліковий запис: ваше повне ім’я
   - Ім’я користувача: логін для терміналу

7. На цьому етапі інсталятор Debian пропонує вибір робочого середовища; оберіть **Cinnamon** для рекомендованого Lumi налаштування.
8. Завершіть встановлення та перезавантажтеся в Debian Stable.

## Налаштування системи

### Масштабування дисплея

Наразі Debian Stable непослідовно обробляє дробове масштабування, особливо на 4K-дисплеях. Замість зменшення роздільної здатності дисплея налаштуйте елементи інтерфейсу безпосередньо.

Рекомендовані зміни:

- Уникайте дробового масштабування дисплея.
- Меню → Вибір шрифту → Параметри шрифту → Коефіцієнт масштабування тексту: `2.5`
- Шрифт робочого столу: `14`
- Панель → Налаштувати → Висота панелі: `60`
- Вигляд панелі → Розмір символічних піктограм правої зони: `48px`
- Миша та сенсорна панель → Розмір указівника
- Робочий стіл (клацніть правою кнопкою) → Налаштувати → Більший розмір значка

Налаштування Firefox:

- Адресний рядок → `about:config`
- Встановіть `layout.css.devPixelsPerPx` у `1`

### Термінал

Налаштуйте параметри терміналу:

1. Меню → Термінал → Редагувати → Параметри
2. Текст → Початковий розмір: `140 columns`, `40 rows`
3. Текст → Власний шрифт: `Monospace 10`
4. Кольори → Вбудовані схеми → Solarized Dark

## Відновлення даних

За потреби відновіть резервні копії файлів у домашній каталог, наприклад:

- `Backup/Home/Artwork` → `~/Artwork`
- `Backup/Home/code` → `~/code`
- `Backup/Home/Desktop` → `~/Desktop`
- `Backup/Home/.ssh` → `~/.ssh`
- `Backup/Home/.config/lumi` → `~/.config/lumi`

Примітка: папки, що починаються з `.`, — приховані каталоги конфігурації в Linux.

## Додатково: налаштування Git

Потрібно лише якщо ви плануєте збирати Lumi або відновлювати репозиторії.

### Встановлення Git

```bash
sudo apt install git
```

Налаштуйте свій профіль Git:

```bash
git config --global --edit
```

#### Доступ до GitLab

Відновіть доступ до репозиторіїв на GitLab або GitHub:

1. Змініть дозволи файлу SSH-ключа: `chmod 600 ~/.ssh/id_rsa`
2. Додайте ключ до ssh-agent: `ssh-add ~/.ssh/id_rsa`
3. Перевірте підключення: `ssh -T git@ssh.gitlab.gnome.org` або `ssh -T git@github.com`

Для кожного репозиторію отримайте останні зміни з віддаленого репозиторію та скиньте локальну гілку відповідно до нього:

```bash
git reset --hard remote-name/branch-name
git clean -df
```

Виконайте `git status`, щоб переконатися, що репозиторії чисті.

Тепер у вас нова ОС із відновленими даними та репозиторіями. Це налаштування відображає перевірене робоче середовище, яке використовується для розробки Lumi, і його можна адаптувати до індивідуальних робочих процесів.

## Збірка Lumi після налаштування ОС

Скрипти збірки Lumi знаходяться тут:

`~/code/lumi-dev/build/lumi/scripts`.

```bash
cd ~/code/lumi-dev/build/lumi/scripts

# Встановити залежності один раз
sudo bash lumi-install-packages.sh

# Перша повна збірка з налаштуванням
bash lumi-build-script.sh --scope setup --dir lumi-dev

# Звичайна перезбірка після змін коду
bash lumi-build-script.sh --scope build --dir lumi-dev

# Швидка компіляція
bash lumi-build-script.sh --scope compile --dir lumi-dev

# Запустити Lumi
bash lumi-launch-active.sh lumi-dev
```

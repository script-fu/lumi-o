Linux — мощная и универсальная операционная система с огромным сообществом разработчиков. В основе системы Linux лежит несколько ключевых компонентов, которые работают вместе, обеспечивая удобство для пользователя. В этом обзоре описаны основные части системы Linux: ядро, дистрибутив, менеджер пакетов, display manager, среда рабочего стола и сервер отображения (X11 или Wayland).

Lumi разрабатывается и тестируется на Debian с Cinnamon (X11). Это по-прежнему среда разработки. Внешний вид приложения и отрисовка OpenGL проверялись в GNOME на Wayland рядом с ней.

### Ключевые термины

#### Ядро

Сердце операционной системы, которое напрямую взаимодействует с оборудованием — обычно Linux.

#### Дистрибутив

Дистрибутив Linux объединяет ядро с инструментами, библиотеками и программами пользовательского пространства. Примеры: Debian, Arch Linux и Fedora.

#### Менеджер пакетов

Инструмент для установки, обновления и удаления приложений из репозиториев. Примеры: APT для дистрибутивов на базе Debian, DNF для Fedora и Pacman для Arch Linux.

#### Менеджер отображения

Управляет графическим экраном входа и запуском сеанса. Примеры: GDM (GNOME Display Manager), LightDM и SDDM (Simple Desktop Display Manager).

#### Среда рабочего стола

Предоставляет графический интерфейс пользователя (GUI) и управляет внешним видом и опытом работы. Примеры: GNOME, Cinnamon и KDE Plasma.

#### Сервер отображения

Управляет выводом изображения и событиями ввода. Примеры: X11 (X Window System) и Wayland. X11 — традиционный сервер отображения; Wayland — более новая и безопасная альтернатива.

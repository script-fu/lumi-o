Bem-vindo aos guias de instalação do Linux para o Lumi.

Estes guias documentam a configuração do sistema operativo usada no desenvolvimento e nos testes do Lumi. Destinam-se a artistas e programadores que pretendem um ambiente Linux estável e reproduzível, em vez de uma configuração personalizada ou experimental.

O foco está em sistemas baseados em Debian, escolhidos pela fiabilidade e consistência a longo prazo. Cada guia segue uma abordagem prática, passo a passo, para ajudar a passar de um sistema existente para uma configuração funcional conhecida, com o mínimo de incerteza.

Os tópicos incluem instalação do Debian, configuração do sistema e cópias de segurança.

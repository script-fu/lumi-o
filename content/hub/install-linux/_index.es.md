Bienvenido a las guías de instalación de Linux para Lumi.

Estas guías documentan la configuración del sistema operativo utilizada para el desarrollo y las pruebas de Lumi. Están pensadas para artistas y desarrolladores que buscan un entorno Linux estable y reproducible, en lugar de una configuración personalizada o experimental.

Nos centramos en sistemas basados en Debian, elegidos por su fiabilidad y coherencia a largo plazo. Cada guía sigue un enfoque práctico paso a paso para ayudarte a pasar de un sistema existente a una configuración conocida y funcional, con la menor incertidumbre posible.

Los temas incluyen la instalación de Debian, la configuración del sistema y las copias de seguridad.

ยินดีต้อนรับสู่คู่มือการติดตั้ง Linux สำหรับ Lumi

คู่มือเหล่านี้อธิบายการตั้งค่าระบบปฏิบัติการที่ใช้สำหรับการพัฒนาและการทดสอบ Lumi เหมาะสำหรับศิลปินและนักพัฒนาที่ต้องการสภาพแวดล้อม Linux ที่เสถียรและทำซ้ำได้ แทนที่จะเป็นการกำหนดค่าแบบกำหนดเองหรือแบบทดลอง

จุดเน้นอยู่ที่ระบบที่ใช้ Debian ซึ่งเลือกมาเพื่อความน่าเชื่อถือและความสม่ำเสมอในระยะยาว คู่มือแต่ละฉบับปฏิบัติตามแนวทางปฏิบัติทีละขั้นตอน เพื่อช่วยให้คุณย้ายจากระบบที่มีอยู่ไปสู่การตั้งค่าที่ใช้งานได้จริงและรู้จักแล้ว โดยมีความไม่แน่นอนน้อยที่สุด

หัวข้อต่างๆ รวมถึงการติดตั้ง Debian การกำหนดค่าระบบ และการสำรองข้อมูล

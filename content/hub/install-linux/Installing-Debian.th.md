เอกสารนี้อธิบายขั้นตอนการติดตั้ง Debian Stable เป็นระบบปฏิบัติการสำหรับการพัฒนา Lumi-o ซึ่งอาจเป็นประโยชน์สำหรับผู้ที่ตั้งค่าสภาพแวดล้อมที่คล้ายกัน

เลือก Debian Stable เพราะ Lumi ต้องการสร้างได้อย่างน่าเชื่อถือบนแพลตฟอร์มระยะยาวที่คาดการณ์ได้ การพัฒนา GIMP มุ่งเป้าไปที่ Debian Testing ทำให้ Debian Stable เป็นระบบฐานที่สอดคล้องกันอย่างใกล้ชิด

Lumi ทำงานได้ดีที่สุดบน Debian กับ Cinnamon (X11) และได้รับการพัฒนาและทดสอบในสภาพแวดล้อมนั้น Cinnamon มอบเวิร์กโฟลว์เดสก์ท็อปที่คุ้นเคยคล้าย Windows ในขณะที่ X11 ให้สภาพแวดล้อมที่เสถียรที่สุดสำหรับการพัฒนา Lumi

หากคุณมาจาก Windows การเปลี่ยนแปลงแนวคิดหลักคือการติดตั้งและการกำหนดค่าซอฟต์แวร์ส่วนใหญ่ทำผ่านตัวจัดการแพ็กเกจและคำสั่งเทอร์มินัลธรรมดา แทนที่จะเป็นตัวติดตั้งที่ดาวน์โหลดได้

## คู่มือนี้เหมาะสำหรับใคร

คู่มือนี้บันทึกการตั้งค่า Debian Stable ที่ใช้งานได้ซึ่งใช้สำหรับการพัฒนา Lumi ไม่ใช่บทช่วยสอนการติดตั้ง Linux ทั่วไป

มีประโยชน์มากที่สุดสำหรับ:

- ศิลปินที่ย้ายจาก Windows และต้องการการตั้งค่า Linux ที่คาดเดาได้
- นักพัฒนาที่สร้าง Lumi จากซอร์สโค้ด
- ผู้ใช้ที่ต้องการทำซ้ำสภาพแวดล้อมการทำงานที่รู้จัก มากกว่าการออกแบบการกำหนดค่าระบบของตนเอง

ถือว่ามีความคุ้นเคยขั้นพื้นฐานกับการแบ่งพาร์ติชันดิสก์และการใช้บรรทัดคำสั่งแบบธรรมดา

## สำรองข้อมูลของคุณ

ก่อนติดตั้ง Debian ให้สร้างการสำรองข้อมูลทั้งหมดของโฮมไดเรกทอรีบนไดรฟ์ภายนอก รวมโฟลเดอร์ข้อมูลเพิ่มเติมที่คุณต้องการเก็บรักษา

หมายเหตุ: ใน Linux `~` แทนโฮมไดเรกทอรีของคุณ

หากคุณใช้ Git repository ให้ push การเปลี่ยนแปลงที่สำคัญไปยัง remote เพื่อให้กู้คืนได้ง่ายหลังการติดตั้ง ขั้นตอนนี้เกี่ยวข้องเฉพาะเมื่อคุณใช้ Git อยู่แล้ว

## สร้างพาร์ติชัน

จัดสรรพื้นที่บนไดรฟ์หลักสำหรับ Debian มีคู่มือและเครื่องมือมากมายสำหรับขั้นตอนนี้ รวมถึง GParted ขึ้นอยู่กับการตั้งค่าของคุณ คุณอาจ:

- ย่อพาร์ติชัน Windows ที่มีอยู่สำหรับ dual boot
- นำพาร์ติชัน Linux ที่มีอยู่กลับมาใช้ใหม่
- เตรียมพาร์ติชัน Linux และ swap ใหม่

หากไม่แน่ใจ ให้ดูคู่มือเฉพาะฮาร์ดแวร์ก่อนทำการเปลี่ยนแปลง เนื่องจากขั้นตอนการแบ่งพาร์ติชันแตกต่างกันมากในแต่ละระบบ


## สร้าง USB ติดตั้ง Debian

สมมติว่ามีพาร์ติชันเป้าหมายและพื้นที่ swap อยู่แล้ว:

1. ดาวน์โหลด ISO ของ Debian จากเว็บไซต์อย่างเป็นทางการ: https://www.debian.org/
2. บน Windows ใช้ BalenaEtcher เพื่อเขียน ISO ลงในไดรฟ์ USB
3. บน Linux ใช้เครื่องมือบรรทัดคำสั่ง เช่น `dd` เพื่อสร้าง USB ที่บูตได้

## ติดตั้ง Debian

1. ใส่ไดรฟ์ USB
2. รีสตาร์ทและกดปุ่มเมนูบูต (โดยทั่วไปคือ `F2`, `F12`, `Esc` หรือ `Del`) ระหว่างการเริ่มต้นระบบ
3. เลือกอุปกรณ์ USB
4. เลือกตัวติดตั้งแบบไม่ใช่กราฟิก
5. ปล่อยรหัสผ่าน root ว่างไว้เมื่อได้รับแจ้ง เพื่อให้ตัวติดตั้งให้สิทธิ์ sudo แก่บัญชีผู้ใช้ของคุณ
6. แบ่งพาร์ติชันด้วยตนเอง:

   - ระบบไฟล์: ext4 (journaling)
   - Swap: พาร์ติชัน swap ที่มีอยู่
   - จุด mount: `/`
   - ป้ายกำกับ: `linux`
   - Hostname: ชื่อระบบที่แสดงเป็น `user@hostname`
   - บัญชีผู้ใช้: ชื่อเต็มของคุณ
   - ชื่อผู้ใช้: ชื่อเข้าสู่ระบบในเทอร์มินัล

7. ตัวติดตั้ง Debian มีตัวเลือกสภาพแวดล้อมเดสก์ท็อปในขั้นตอนนี้ เลือก **Cinnamon** สำหรับการตั้งค่าที่ Lumi แนะนำ
8. ติดตั้งให้เสร็จและรีบูตเข้าสู่ Debian Stable

## การตั้งค่าระบบ

### การปรับขนาดการแสดงผล

ปัจจุบัน Debian Stable จัดการการปรับขนาดแบบเศษส่วนได้ไม่สม่ำเสมอ โดยเฉพาะบนจอ 4K แทนที่จะลดความละเอียดของจอ ให้ปรับองค์ประกอบอินเทอร์เฟซโดยตรง

การปรับที่แนะนำ:

- หลีกเลี่ยงการปรับขนาดจอแบบเศษส่วน
- Menu → Font Selection → Font Settings → Text Scaling Factor: `2.5`
- Desktop Font: `14`
- Panel → Customize → Panel Height: `60`
- Panel Appearance → Right Zone Symbolic Icon Size: `48px`
- เมาส์และทัชแพด → ปรับขนาดตัวชี้
- Desktop (right-click) → Customize → Larger icon size

การปรับ Firefox:

- Address bar → `about:config`
- ตั้งค่า `layout.css.devPixelsPerPx` เป็น `1`

### เทอร์มินัล

กำหนดการตั้งค่าเทอร์มินัล:

1. Menu → Terminal → Edit → Preferences
2. Text → Initial size: `140 columns`, `40 rows`
3. Text → Custom font: `Monospace 10`
4. Colours → Built-in schemes → Solarized Dark

### ปุ่ม Alt สำหรับปรับขนาดเครื่องมือ

หาก `Alt` + คลิกขวาแล้วลาก ไม่ปรับขนาดแปรงใน Lumi แสดงว่าระบบเดสก์ท็อปใช้ Alt สำหรับการจัดการหน้าต่าง

1. ค้นหา **หน้าต่าง** ในเมนูระบบ
2. หน้าต่าง → ลักษณะการทำงาน → ปุ่มพิเศษที่ใช้ย้ายและปรับขนาดหน้าต่าง → **ปิดใช้งานแล้ว**

หลังจากการเปลี่ยนแปลงนี้ `Alt` + คลิกขวาแล้วลาก ควรใช้งานได้ใน Lumi สำหรับการปรับขนาดเครื่องมือ

## กู้คืนข้อมูล

กู้คืนไฟล์ที่สำรองไว้ไปยังโฮมไดเรกทอรีตามต้องการ ตัวอย่างเช่น:

- `Backup/Home/Artwork` → `~/Artwork`
- `Backup/Home/code` → `~/code`
- `Backup/Home/Desktop` → `~/Desktop`
- `Backup/Home/.ssh` → `~/.ssh`
- `Backup/Home/.config/lumi` → `~/.config/lumi`

หมายเหตุ: โฟลเดอร์ที่ขึ้นต้นด้วย `.` เป็นไดเรกทอรีการกำหนดค่าที่ซ่อนอยู่ใน Linux

## ตัวเลือก: การตั้งค่า Git

จำเป็นเฉพาะเมื่อคุณวางแผนจะสร้าง Lumi หรือกู้คืน repository

### ติดตั้ง Git

```bash
sudo apt install git
```

กำหนดค่าข้อมูลประจำตัวของคุณ:

```bash
git config --global --edit
```

#### การเข้าถึง GitLab

กู้คืนการเข้าถึง repository ไปยัง GitLab หรือ GitHub:

1. เปลี่ยนสิทธิ์ของไฟล์คีย์ SSH: `chmod 600 ~/.ssh/id_rsa`
2. เพิ่มคีย์เข้า ssh-agent: `ssh-add ~/.ssh/id_rsa`
3. ทดสอบการเชื่อมต่อ: `ssh -T git@ssh.gitlab.gnome.org` หรือ `ssh -T git@github.com`

สำหรับแต่ละ repository ให้ดึง remote และรีเซ็ต branch ในเครื่องให้ตรงกัน:

```bash
git reset --hard remote-name/branch-name
git clean -df
```

เรียกใช้ `git status` เพื่อยืนยันว่า repository สะอาด

ตอนนี้คุณมีระบบปฏิบัติการใหม่พร้อมข้อมูลและ repository ที่กู้คืนแล้ว การตั้งค่านี้สะท้อนสภาพแวดล้อมการทำงานที่รู้จักสำหรับการพัฒนา Lumi และสามารถปรับให้เข้ากับขั้นตอนการทำงานส่วนบุคคลได้ตามต้องการ

## สร้าง Lumi หลังตั้งค่าระบบปฏิบัติการ

สคริปต์ build ของ Lumi อยู่ที่:

`~/code/lumi-dev/build/lumi/scripts`.

```bash
cd ~/code/lumi-dev/build/lumi/scripts

# Install dependencies once
sudo bash lumi-install-packages.sh

# First full setup build
bash lumi-build-script.sh --scope setup --dir lumi-dev

# Regular rebuild after code changes
bash lumi-build-script.sh --scope build --dir lumi-dev

# Quick compile path
bash lumi-build-script.sh --scope compile --dir lumi-dev

# Launch Lumi
bash lumi-launch-active.sh lumi-dev
```

印刷・出版向けのイラストには、キャンバスサイズ以上の情報が必要になることが多いです。ページには裁ち落とし後の端があり、見開きには中央の綴じ目があり、重要な内容は切り落とされる領域やのど（ガター）から避ける必要があります。Lumi の Publishing Layout ツールは、それらの要件を作品に焼き込まず、描画中も見えるまま保ちます。

レイアウト境界は画像ごとに保存され、プロジェクトと一緒に残り、不要なときはオフにできます。目的は、書籍、漫画、印刷ワークフローにページ構造の感覚を与えつつ、下のレイヤー画像を完全に編集可能なまま保つことです。

## 裁ち落としとトリム

裁ち落とし（ブリード）は、作品が最終ページ端をどこまで越えて描かれるかを定義します。Lumi はトリム領域をキャンバス内の実ページ境界として示し、裁ち落とし余白をその外側のシェードオーバーレイとして表示します。仕上がり位置を推測せず、断裁後も残すべき背景や端のディテールを描きやすくなります。

単位は作業に合わせて設定できるため、裁ち落としをピクセルだけでなく、インチ、ミリメートルなど慣れている印刷単位で考えられます。

## のどと見開き

見開きページでは、のど（ガター）が綴じ側の保護ゾーンを示し、重要な内容を避けるべき領域をマークします。有効にすると、Lumi は見開き全体にガターバンドを表示するため、顔や文字、焦点を綴じ部分から外しつつ、見開き全体を一続きのキャンバスのまま保てます。

漫画、絵本、対ページとして印刷される作品に特に有用です。

## 構図ガイド

任意のエッジガイドは、トリム後のページ領域に控えめな構図目盛を付けます。ガイドはページ単位の分割や見開き全体の読み方に従え、レイアウトの見方に応じて三分割、黄金比、五分割を選べます。

ガイドはレイアウトや仕上げ作業中の静かな参照用です。デジタルキャンバス全体だけでなく、実際に印刷されるページに対して配置を判断するのに役立ちます。

## キャンバス上でのレイアウト表示

レイアウトオーバーレイは View メニューから制御します。裁ち落とし、のど、ガイド領域は個別またはまとめて表示でき、その時点で必要な出版構造に集中できます。

Image > Enable layout で、現在の画像のレイアウト境界をオン・オフします。レイアウトを無効にするとオーバーレイは隠れ、表示トグルも退きますが、境界設定はファイルに保存されたまま後で使えます。

## プロジェクトに保存

レイアウト設定は `.lum` プロジェクトと一緒に移動します。後で画像を開くと、裁ち落とし、のど、オーバーレイの見た目、ガイドの選択、そのファイルでレイアウトが有効かどうかが復元されます。一時的な表示設定ではなく、出版を意識した設定が作品の作業状態の一部として残ります。

スケッチ、描画、印刷準備を行き来するアーティストにとって、ワークフローは一か所に留まります。同じレイヤー画像のまま、ページが必要なときいつでも出版構造を呼び出せます。

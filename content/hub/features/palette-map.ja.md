Palette Map は、アクティブなパレットが生み出せる色の世界を可視化します。パレットの顔料と保存色から出発し、到達可能な色空間を、画家が使いやすい色相と明度のマップとして示します。

目的は実用的です。平坦なスウォッチ一覧を眺める代わりに、色同士の位置関係を見ながら、パレットの中を空間的に移動できます。

![palette-map](/images/screens/palettemap.jpg)

## 到達可能な色の地図

どのパレットにも個性があります。鮮やかな緑や紫へ広がるものもあれば、すぐに暖かいニュートラル、アースカラー、くすんだ影へ寄るものもあります。Palette Map はその個性を見えるようにします。

![palette-map-zorn](/images/screens/palettemap-zorn.jpg)

生成ミックス、主要顔料、保存色が、一つの整理された色のフィールドとして並びます。どの色があるかだけでなく、パレット全体のレンジとの関係も把握しやすくなります。

## 色相、明度、向き

マップは色相と明度を軸に配置されるため、色選びに安定した視覚的な位置があります。明るい色、暗い色、暖かい方向、寒い方向、彩度の高い領域、静かな領域を一目で比較しやすくなります。

この空間構造は、次に使う色を選ぶときに特に有用です。近い色相へ移り、同じ明度帯に留まり、彩度を強く探し、意図的に静かなニュートラルへ踏み込めます。

## ピッカー以上のもの

Palette Map は混色への橋でもあります。マップ上の色は新しい混色の出発点になり、保存ミックスも切り離されたスウォッチではなく、マップとの関係を保てます。

これにより、Lumi は色を連続した作業空間として扱えます。選ぶ、混ぜる、保存する、戻る——すべてが同じパレットの地理の中で起こります。

## キャンバス中心の探索

色の判断にもっと余白が必要なとき、マップを大きな視覚面として使えます。候補色を絵そのものと比べたり、トーンのファミリーを眺めたり、小さなパネルに頼らずパレットを素早く移動したりするのに向いています。

意図は、パレット操作を即座で視覚的に感じさせることです。色の世界を見て、その中を動き、次にふさわしいマークを選びます。

## パレットのアイデンティティ

Palette Map はアクティブなパレットから生成されるため、パレットを切り替えるとマップの形と強調も変わります。限られた肖像パレット、フルスペクトルのスタジオパレット、くすんだ風景パレットは、それぞれ異なる色の地理を生み出します。

こうして Palette Map は、パレットそのものの肖像——そのカラーシステムが何を成し得るかを読み取れる図——になります。

Palette Map 視覺化目前調色盤能夠產生的顏色。它從調色盤的顏料與已儲存顏色出發，將可及的色彩空間呈現為便於畫家探索與選色的色相—明度地圖。

它的目的很實際：藝術家不必在扁平的色票列表中翻找，而是可以看到顏色之間的相對位置，並在調色盤中按空間關係移動。

![palette-map](/images/screens/palettemap.jpg)

## 可及色彩的地圖

每個調色盤都有自己的性格。有的調色盤會展開成清晰的綠色與紫色；有的則很快收斂為暖中性色、大地色或柔和的暗部。Palette Map 讓這種性格一目了然。

![palette-map-zorn](/images/screens/palettemap-zorn.jpg)

產生的混色、主顏料與已儲存顏色共同構成一個有序色域。這樣不僅能看清有哪些顏色，也能理解它們與調色盤整體範圍的關係。

## 色相、明度與方向

地圖按色相與明度排列，為每種顏色選擇提供穩定的視覺座標。亮色、暗色、暖向變化、冷向變化、飽和區域與低飽和段落都更容易一眼比較。

選擇繪畫中的下一顏色時，這種空間結構尤其有用。藝術家可以移向鄰近色相、停留在同一明度家族、尋找更高色度，或刻意步入更安靜的中性色區域。

## 不只是取色器

Palette Map 也是進入混色的橋梁。地圖上的顏色可以作為新混色的起點；已儲存的混色也能保持與地圖的關係，而不會變成孤立的色塊。

這有助於 Lumi 把色彩當作連續的工作空間。取色、混色、儲存與回到某個顏色，都在同一套調色盤地理中完成。

## 以畫布為中心的探索

當色彩決策需要更大視野時，地圖可以作為大型視覺介面使用。它便於將候選顏色與畫作本身比較、瀏覽明度家族，或在不依賴小面板的情況下快速瀏覽調色盤。

目標是讓調色盤導覽直觀而視覺化：觀察色彩世界，在其中移動，選出下一筆應屬的顏色。

## 調色盤的身份

由於 Palette Map 由目前調色盤產生，切換調色盤會改變地圖的形狀與重點。有限的肖像調色盤、全光譜工作室調色盤與低飽和風景調色盤，各自呈現不同的色彩地理。

從這個意義上說，Palette Map 也是調色盤本身的肖像：一張可讀的圖片，展示該色彩系統能做什麼。

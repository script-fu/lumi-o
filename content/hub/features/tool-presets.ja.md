ツールプリセットは Lumi のツールワークフローの中心です。すべてのツールはプリセットを通じて使われ、静かなデフォルトでも、アーティストが保存した手作りツールでも同じです。ツールの挙動が見え、意図的で、再現可能になります。

考え方はシンプルです。小さく安定した使い慣れたツールセットを作り、はっきりしたアイデンティティを与え、スタジオで別のブラシやペン、ナイフ、ブレンダーに手を伸ばすように自然に切り替えます。

## 手作りツールであり、設定の寄せ集めではない

ツールプリセットは保存した調整値以上のものです。ツールのアイデンティティ、操作感、セットアップの選択、必要なら専用ブラシ、ダイナミクス、グラデーション、アイコンまで含む、完成したツールです。

お気に入りのスケッチ鉛筆はスケッチ鉛筆のまま、ブロッキングブラシは幅広くシンプルな性格を保ち、仕上げブラシは精密で馴染みのある道具のまま——毎回記憶から組み立てるのではなく、知っている道具として選べます。

## すっきりした Tool Options

Lumi は、作業中に触るコントロールと、ツールの設計を決めるコントロールを分けます。頻繁に使うその場の調整はキャンバス近くに、低頻度のセットアップは専用のプリセット編集画面へ移します。

Tool Options エリアは描画中に軽く読みやすく保たれます。ストロークや編集の流れで重要なコントロールだけが見え、深い設計作業は日常 UI を圧迫せずに利用できます。

## プリセットの設計

Tool Preset Editor では、ツールを意図的に作り込めます。名前、視覚的アイデンティティ、残す価値のある深い挙動を与えます。

描画ツールでは、マークの性格を決めるブラシリソースとダイナミクスを含められます。他のツールでは、特定の編集操作を一貫させる設定と作業スタイルを保てます。同じプリセットの考え方がツール全体に及ぶため、Lumi は作成したツール状態を描画専用の便利機能ではなく共有システムとして扱います。

## 視覚的なツール棚

保存したプリセットはカスタムアイコン付きのツールボタンのように並べられます。匿名の設定一覧ではなく、手作りツールの棚として認識できます。

見た目のアイデンティティも重要です。形、色、アイコン、習慣で道具を選び、物理素材と同じ筋肉記憶を築けます。信頼できる少数のプリセットは、設定を探し直すより速く、より個人的です。

## ワークスペース対応のツールキット

ツールプリセットは Workspaces と組み合わせると特に強力です。描画ワークスペースは描画ツールを、インキングワークスペースはきれいな線のプリセットを、ペイントワークスペースは色・テクスチャ・ブレンド向けブラシを前面に出せます。

Tool Presets ドックでは、アクティブなワークスペースのプリセットだけを非表示にできます。非表示のプリセットはディスクに残り、Lumi の他の場所では使えます。各ワークスペースは独自の非表示リストとカスタム順序を覚えるため、ファイルを移動・削除せず短い個人棚を保てます。

ワークスペースを変えると、ドックに現れるプリセット、順序、開いているパネルも変わります。スタジオはレイアウトを変えるだけでなく、今の作業に合う道具を取り替えることもできます。

## ツール切り替えの安定性

すべてのツールがプリセット経由で動くため、切り替えても最後の有用な状態を失う必要はありません。Lumi は各ツールをアクティブなプリセットに結び付けたままにでき、戻ったとき馴染みの道具がそのまま呼び戻されます。

鉛筆、ブラシ、変形ツール、選択ツールが、見えないツール別オプションファイルに頼らず、それぞれ設計した状態を覚えます。

## 持ち運べる設計

プリセットは独自の印象を与えるリソースを内包します。ブラシプリセットでは、ブラシ、ダイナミクス、アイコンがプリセット自身の中にあり、ライブラリ全体が変わってもツールは完成したままです。

保存したツールは、いくつかの部品への脆い参照ではありません。ブラシは再利用ライブラリにも保存できますが、プリセットに選ばれたときはその設計済みツールへコピーされます。

アーティストにとって重要なのは、ツールを創作判断の一式として保存できることです。挙動、アイデンティティ、リソースが一緒に移動し、ツールプリセットが個人ワークフロー、プロジェクト別キット、共有スタジオ設定の実用的な基盤になります。

## 馴染みの道具セット

目標は数百のプリセットを管理させることではありません。少数のよくできた道具が安定し、認識でき、手の届くところにある感覚を作ることです。

Lumi のプリセットシステムは、そのリズムを支えます。一度道具を作り、時間をかけて磨き、視覚的アイデンティティを与え、各ワークスペースが適切な道具を手元に置けるようにします。

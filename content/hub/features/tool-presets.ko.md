도구 사전 설정은 Lumi 도구 작업흐름의 중심입니다. 모든 도구는 조용한 기본값이든 아티스트가 저장한 수제 도구이든 사전 설정을 통해 사용됩니다. 이를 통해 도구 동작이 가시화되고 의도적이며 반복 가능해집니다.

아이디어는 간단합니다. 아티스트는 작고 안정적인 친숙한 도구 세트를 만들고 명확한 정체성을 부여하며 스튜디오에서 다양한 브러시, 펜, 칼 또는 블렌더를 사용하는 것처럼 자연스럽게 도구 사이를 전환합니다.

## 느슨한 설정이 아닌 수제 도구

도구 사전 설정은 저장된 조정 이상의 의미를 갖습니다. 도구 정체성, 작업 느낌, 설정 선택 사항, 필요한 경우 개인 브러시, 역학, 그라디언트 또는 아이콘 등 완전히 제작된 도구입니다.

이를 통해 사전 설정이 아티스트 툴킷의 실제 개체처럼 작동할 수 있습니다. 좋아하는 스케치 연필은 스케치 연필로 남을 수 있습니다. 차단 브러시는 광범위하고 단순한 특성을 유지할 수 있습니다. 마무리 브러시는 정확하고 친숙한 상태를 유지할 수 있습니다. 도구는 매번 메모리에서 다시 작성되지 않습니다. 알려진 도구로 선택됩니다.

## 더욱 차분해진 도구 옵션 영역

Lumi는 도구 제작 방법을 정의하는 컨트롤과 작업하는 동안 변경되는 컨트롤을 분리합니다. 빈번하고 즉각적인 조정은 캔버스에 가깝게 유지됩니다. 저주파 설정 선택 사항은 전용 사전 설정 편집 공간으로 이동합니다.

이렇게 하면 페인팅 중에 도구 옵션 영역이 더 가볍고 읽기 쉬워집니다. 아티스트는 획이나 편집의 흐름에 중요한 컨트롤을 확인하면서 일상적인 인터페이스를 혼잡하게 하지 않고도 더 깊은 저작물을 사용할 수 있습니다.

## 사전 설정 저작

도구 사전 설정 편집기는 도구가 의도적으로 만들어지는 곳입니다. 이는 사전 설정에 이름, 시각적 정체성 및 유지할 가치가 있는 더 깊은 동작을 제공합니다.

페인트 도구의 경우 여기에는 마크의 특성을 정의하는 브러시 리소스와 동적 동작이 포함될 수 있습니다. 다른 도구의 경우 특정 편집 작업이 일관되게 느껴지도록 하는 설정과 작업 스타일을 유지할 수 있습니다. 동일한 사전 설정 아이디어가 도구 세트 전체에 적용되므로 Lumi는 작성된 도구 상태를 페인트 전용 편의가 아닌 공유 시스템으로 처리합니다.

## 시각적 도구 선반

저장된 사전 설정은 사용자 정의 아이콘과 함께 도구 버튼처럼 표시될 수 있습니다. 이렇게 하면 사전 설정 컬렉션이 익명 구성 목록이 아닌 인식 가능한 수제 도구 선반으로 변합니다.

시각적 아이덴티티가 중요합니다. 아티스트는 모양, 색상, 아이콘 및 습관에 따라 도구를 선택하여 물리적 재료를 사용하여 개발한 것과 동일한 종류의 근육 기억을 구축할 수 있습니다. 신뢰할 수 있는 사전 설정의 작은 행은 설정을 반복적으로 검색하는 것보다 더 빠르고 개인화될 수 있습니다.

## 작업 공간 인식 툴킷

도구 사전 설정은 작업 공간과 결합되면 특히 강력해집니다. 그리기 작업 영역에서는 그리기 도구를 향상시킬 수 있고, 잉크 입력 작업 영역에서는 깔끔한 선 사전 설정을 선호할 수 있으며, 페인팅 작업 영역에서는 색상, 질감 및 혼합용으로 제작된 브러시로 전환할 수 있습니다.

도구 사전 설정 독에서는 활성 작업 공간에 대해서만 사전 설정을 숨길 수 있습니다. 숨겨진 사전 설정은 디스크에 남아 있으며 Lumi의 다른 곳에서 사용할 수 있습니다. 각 작업 공간은 사용자 정의 사전 설정 순서와 함께 자체 숨겨진 목록을 기억하므로 파일을 이동하거나 삭제하지 않고도 짧은 개인 선반을 유지할 수 있습니다.

작업 영역을 변경하면 도크에 표시되는 사전 설정, 순서 지정 방식, 열려 있는 패널이 변경될 수 있습니다. 스튜디오는 레이아웃을 재정렬할 뿐만 아니라; 현재 작업에 속한 도구를 스스로 재입고할 수 있습니다.

## 도구 스위치 전반에 걸친 안정성모든 도구는 사전 설정을 통해 작동하므로 도구를 전환한다고 해서 마지막으로 사용했던 상태가 손실되는 것은 아닙니다. Lumi는 각 도구를 활성 사전 설정에 연결된 상태로 유지할 수 있으므로 도구로 돌아가면 아티스트가 사용했던 친숙한 도구가 다시 나타납니다.

이로 인해 도구 전환이 안정적으로 느껴집니다. 연필, 브러시, 변형 도구 또는 선택 도구는 보이지 않는 도구별 옵션 파일에 의존하지 않고도 각각 작성된 상태를 기억할 수 있습니다.

## 휴대용 저작자

사전 설정은 고유한 느낌을 주는 리소스를 소유합니다. 브러시 사전 설정의 경우 브러시, 역학 및 아이콘이 사전 설정 자체 내에 있으므로 더 넓은 리소스 라이브러리가 변경되더라도 도구는 완전한 상태로 유지됩니다.

이는 의도적인 단순화입니다. 저장된 도구는 여러 개별 움직이는 부품에 대한 깨지기 쉬운 포인터가 아닙니다. 브러시는 재사용 가능한 라이브러리에 저장할 수 있지만 사전 설정으로 선택하면 해당 제작 도구에 복사됩니다.

아티스트에게 중요한 부분은 도구가 완전한 창의적 결정으로 저장될 수 있다는 것입니다. 동작, ID 및 리소스가 함께 이동하여 도구 사전 설정을 개인 작업 흐름, 프로젝트별 도구 키트 및 공유 스튜디오 설정을 위한 실용적인 기반으로 만듭니다.

## 친숙한 악기 세트

전반적인 목표는 아티스트가 수백 개의 사전 설정을 관리하도록 하는 것이 아닙니다. 잘 만들어진 작은 도구 세트가 안정적이고 인식 가능하며 가까이 있는 느낌을 주는 것입니다.

Lumi의 사전 설정 시스템은 이러한 종류의 작업 리듬을 지원합니다. 도구를 한 번 만들고, 시간이 지남에 따라 다듬고, 시각적 아이덴티티를 부여하고, 각 작업 공간에 올바른 도구를 배치할 수 있도록 합니다.

Warp Tool は、描いた内容をキャンバス上で直接押したり、引いたり、曲げたり、柔らかくしたり、形を変えたりできます。比例の修正、流れの追加、シルエットの微調整、仕上がった形に動きを与える——一から描き直さない表現的な調整のためのツールです。

Lumi では、ワープはとくにレイヤー作品の保持に重点を置いています。複雑な被写体を視覚的な全体として形を変えつつ、下のレイヤーとマスクは引き続き編集できます。

## キャンバス上での直接変形

ワープは、画像に動きを刷り込むような感覚です。硬い変形ボックスを選ぶ代わりに、局所的にストロークで変位を重ね、形が正しい位置に来るまで調整できます。

微妙な修正から大胆な歪みまで使えます。頬を柔らかくし、袖にリズムを与え、葉に流れを足し、スケッチを意図したジェスチャーに近づけられます。

## グループ対応のワープ

レイヤーイラストでは、線画、色、陰影、テクスチャ、マスク、エフェクトが分かれていることが多いです。構造の一部を統合して形を変えると、編集可能にしてきた組織そのものを壊してしまいます。

Lumi の Warp Tool は、レイヤーグループを内部の要素を保ったまま、一つの見える被写体として扱うよう設計されています。合体した見た目を形作り、変更後も内部レイヤーをそのまま残せます。

## マスクと構造

マスクは後付けではなく、作品構造の一部です。ワープした被写体がエッジ、切り抜き、陰影、グループ境界のマスクに依存しているなら、その関係も画像と一緒に動く必要があります。

Lumi の方式では、内容とマスクが揃ったまま編集結果の一貫性を保ちます。プレビューしたワープと確定したレイヤー結果が視覚的に一致し、アーティストが子レイヤーを一つずつ手で直す必要がないことが目標です。

## 反復的な調整

ワープは試行錯誤が自然です。一筆試し、結果を比較し、柔らかくし、取り消し、少しずつ強い変化を重ねる——そんな作業が多いです。

Warp Tool はセッション中、作業中のワープを調整可能なまま保ち、その種の反復を支えます。通常の元に戻す履歴へ確定する前に、変位を磨き込めます。

## 創造的な用途

修正以外にも、ワープはマーク作りやデザインの道具になります。髪や布に動きを加え、表情を誇張し、グラフィック形状を曲げ、テクスチャに波を起こし、手描きでは難しい絵画的な歪みを作れます。

レイヤー被写体と連動するため、初期の大まかな形作りから後工程の仕上げまで使え、描画プロセスを柔軟なまま画像の形を変えられます。

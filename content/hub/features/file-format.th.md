รูปแบบ `.lum` ของ Lumi เป็นไดเรกทอรีโปรเจ็กต์ ไม่ใช่ไฟล์เดียวที่ปิดผนึก ออกแบบมาสำหรับงานวาดแบบเลเยอร์: ต้นไม้เลเยอร์ที่ลึก ผืนผ้าใบขนาดใหญ่ มาสก์ เอฟเฟกต์แบบไม่ทำลาย และจุดตรวจสอบที่ไม่ต้องทำสำเนาภาพทั้งภาพ

หน้าที่ของรูปแบบคือรักษาโครงสร้างการทำงานนั้นให้ครบ — เพื่อให้เปิดโปรเจ็กต์กลับมาได้ตรงตามเดิม ตรวจสอบได้เมื่อมีปัญหา และกู้คืนจากจุดตรวจสอบล่าสุดได้ โดยไม่ต้องมองงานเป็นก้อนทึบก้อนเดียว

## แยกชิ้นส่วนไว้โดยตั้งใจ

โปรเจ็กต์ `.lum` คือโฟลเดอร์ ต้นไม้เลเยอร์และคุณสมบัติของภาพอยู่ใน XML ที่อ่านได้ แต่ละเลเยอร์และมาสก์เก็บบัฟเฟอร์พิกเซลของตัวเอง โดยตั้งชื่อตามงาน ไม่ใช่ตามรหัสภายใน เส้นเวกเตอร์เก็บเป็น SVG ธรรมดา การตั้งค่าฟิลเตอร์ที่หนักอยู่ในไฟล์แยกข้างภาพ โปรไฟล์ ICC เก็บครั้งเดียวที่รากโปรเจ็กต์ เพื่อให้สแน็ปช็อตการกู้คืนอ้างถึงได้โดยไม่ต้องคัดลอก

การแยกแบบนี้ทำให้ส่วนอื่นของรูปแบบเป็นไปได้ เลเยอร์ที่ไม่เปลี่ยนสามารถปล่อยไว้บนดิสก์ บัฟเฟอร์ที่เสียหายล้มเหลวเฉพาะตัว โดยไม่ลากไฟล์ทั้งไฟล์ไปด้วย พิกเซลเลเยอร์ที่หายไปกลายเป็นเลเยอร์ว่างที่ยังมีชื่อ ตำแหน่ง และค่าการผสม ส่วนภาพรวมของกลุ่มที่หายไปจะถูกสร้างใหม่จากเลเยอร์ลูก โปรเจ็กต์ยังคงเป็นแผนที่ว่าภาพถูกสร้างอย่างไร

จานสีแบบเม็ดสียังอยู่กับเครื่องมือสีของ Lumi โปรเจ็กต์จำได้ว่าจานสีใดผูกกับภาพ แต่คลังจานสีเองอยู่ภายนอก `.lum`

## สถานะที่แก้ไขได้ ไม่ใช่ภาพแบน

ไฟล์เก็บภาพที่กำลังทำงาน เลเยอร์ยังเป็นเลเยอร์ กลุ่มเลเยอร์ยังเป็นกลุ่ม และมาสก์ยังเป็นมาสก์ รวมทั้งออฟเซ็ต การล็อก พฤติกรรมการผสม และชุดฟิลเตอร์ ฟิลเตอร์แบบไม่ทำลายถูกบันทึกเป็นการดำเนินการและพารามิเตอร์ ไม่ใช่พิกเซลที่ผนวกเข้าไปแล้ว เลเยอร์ที่เป็นสีเรียบสีเดียวไม่ต้องมีไฟล์พิกเซลเลย

กลุ่มที่ยุบไว้ยังเก็บภาพที่ผสมแล้วของตัวเอง ภาพรวมที่บันทึกไว้นั้นคือสิ่งที่ปรากฏบนผืนผ้าใบเมื่อกลุ่มถูกปิด จึงไม่ต้องประกอบเลเยอร์ลูกใหม่เพียงเพื่อดูภาพ โหมดตรวจดูที่ใช้แสดงผลอย่างเดียวไม่อยู่ในแคชนั้น: การแสดงมาสก์หรืออัลฟาเพื่อแก้ไขถูกคืนเป็นข้อมูลเมตา ไม่ได้ถูกผนวกเข้ากับกลุ่มที่บันทึกไว้

## ไฟล์ใหญ่สามารถคงบางส่วนไว้บนดิสก์

การเปิด `.lum` ไม่จำเป็นต้องโหลดทุกพิกเซล เนื้อหาในกลุ่มที่ยุบไว้สามารถอยู่บนดิสก์ต่อไป ขณะที่ภาพรวมที่บันทึกไว้ของกลุ่มแสดงทันที การขยายกลุ่มคือตอนที่เลเยอร์ มาสก์ และกลุ่มที่ซ้อนอยู่ภายในเข้าสู่หน่วยความจำ กลุ่มที่ปิดอยู่ยังคงเบา

ไฟล์ยังบันทึกว่ากลุ่มใดถูกใช้งานจริง กลุ่มที่อยู่ในเส้นทางการเลือกปัจจุบันสามารถเปิดใหม่ในสภาพขยายได้ ส่วนโฟลเดอร์อื่นถูกเก็บเป็นแบบยุบ แม้ในเซสชันที่แล้วจะเปิดอยู่ นั่นป้องกันไฟล์ที่มีโครงสร้างลึกไม่ให้โหลดทุกสาขาที่ไม่ได้ใช้เข้าหน่วยความจำทันทีที่เปิด

การจัดกลุ่มจึงเป็นทั้งทางเลือกด้านประสิทธิภาพและด้านองค์กร แผ่นพื้นหลังขนาดใหญ่ การทดลองที่เก็บไว้ และแบบทางเลือกที่ไม่ได้ใช้ สามารถอยู่ในกลุ่มที่ปิด โดยไม่ใช้หน่วยความจำเท่าเลเยอร์ที่กำลังวาด การบันทึกใช้กฎเดียวกัน: บัฟเฟอร์ที่ยังซ่อนอยู่ถูกคัดลอกหรือข้ามในฐานะไฟล์ ไม่ถูกดึงกลับเข้าหน่วยความจำเพียงเพื่อเขียนออกไปอีกครั้ง

## จุดตรวจสอบที่เขียนเฉพาะส่วนที่เปลี่ยน

ไฟล์ → บันทึก จะอัปเดตโปรเจ็กต์ที่กำลังทำงาน การบันทึกแบบส่วนเพิ่มและการบันทึกอัตโนมัติเขียนลงต้นไม้การกู้คืน และเขียนเฉพาะข้อมูลที่เปลี่ยน — บัฟเฟอร์เลเยอร์ที่เปลี่ยน ไม่ใช่สำเนาที่สองของภาพทั้งภาพ แต่ละจุดตรวจสอบยังมีคำอธิบายต้นไม้เลเยอร์ครบ ดังนั้นจุดใดในเส้นทางนั้นก็เปิดได้ โดยเติมพิกเซลที่ไม่เปลี่ยนจากจุดตรวจสอบเก่ากว่า และจากไฟล์งานเองถ้าจำเป็น

การบันทึกอัตโนมัติใช้แบบแผนเดียวกันในแคชแยก ดังนั้นการป้องกันอัตโนมัติไม่ต้องเขียนไฟล์บนดิสก์ใหม่ หากเปิดโปรเจ็กต์แล้วมีจุดตรวจสอบใหม่กว่าการบันทึกเต็มครั้งล่าสุด Lumi สามารถเสนอจุดนั้นได้ แทนที่จะทิ้งงานที่ใหม่กว่าโดยไม่บอก ภาพที่กู้คืนเปิดด้วยชื่อต่างออกไป เพื่อไม่ให้การบันทึกเร็วไปทับของเดิม

## รูปแบบสำหรับงานที่ทำต่อ

`.lum` มีไว้เพื่อวาดต่อใน Lumi รูปแบบที่รวมชั้นแล้วหรือเน้นความเข้ากันได้มีไว้เผยแพร่ ส่งมอบ และใช้กับแอปพลิเคชันอื่น เพราะโปรเจ็กต์เป็นไดเรกทอรีของหลายไฟล์ จึงควรทำเป็นไฟล์เก็บถาวรหากต้องนำไปที่อื่น

ไฟล์งานยังคงสมบูรณ์และแก้ไขได้ การส่งออกคือวิธีที่ภาพสำเร็จหรือภาพที่แชร์ออกจากโครงสร้างนั้น

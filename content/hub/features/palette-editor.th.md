Palette Editor คือจุดที่จานสี Lumi กลายเป็นสภาพแวดล้อมที่มีสีสมบูรณ์ โดยเป็นการนำเม็ดสีที่ใช้สร้างพาเล็ตต์ ส่วนผสมที่ศิลปินเลือกที่จะเก็บไว้ สีที่ใช้ระหว่างการวาดภาพ และโครงสร้างโทนสีที่กำหนดวิธีสำรวจพาเล็ต

จานสีใน Lumi เป็นมากกว่ารายการตัวอย่าง มันเป็นระบบสีที่ใช้งานได้: ชุดของส่วนผสม ส่วนผสมที่จดจำ ความสัมพันธ์ของค่า และการไล่ระดับสีที่สามารถเป็นแนวทางให้กับงานสีทั้งหมดหรือเนื้องานได้

![palette-editor](/images/screens/palette-editor.jpg)

## จานสีเป็นข้อจำกัดทางศิลปะ

นักทาสีหลายคนทำงานได้ดีที่สุดกับชุดสีที่คุ้นเคยจำนวนจำกัด ชุดเม็ดสีขนาดเล็กสามารถสร้างความสามัคคี สร้างอารมณ์ และตัดสินใจเรื่องสีได้เร็วขึ้น เนื่องจากส่วนผสมทุกอย่างอยู่ในกลุ่มภาพเดียวกัน

โปรแกรมแก้ไข Palette รองรับข้อจำกัดโดยเจตนาเช่นนั้นตลอดจนจานสีเต็มสเปกตรัมที่กว้างขึ้น ศิลปินสามารถแยกจานสีสำหรับวัตถุ โปรเจ็กต์ สไตล์ หรือสภาพแสงที่แตกต่างกัน โดยแต่ละจานมีลักษณะเฉพาะและพฤติกรรมการผสมของตัวเอง


![palette-editor-zorn](/images/screens/palette-editor-zorn.jpg)


## เม็ดสี สารผสม และความทรงจำ

เม็ดสีจานสีทำหน้าที่เป็นรากฐาน โดยจะกำหนดสีส่วนที่เหลือของระบบและมีอิทธิพลต่อการผสมที่สร้างขึ้นซึ่งมีอยู่ในเครื่องมือสีของ Lumi

การผสมที่บันทึกไว้แสดงถึงการค้นพบโดยเจตนา: สีที่ควรค่าแก่การเก็บรักษา การตั้งชื่อ และการกลับมาใช้ สีที่ใช้จะสร้างความทรงจำที่เงียบกว่า โดยคงสีที่สร้างไว้บนผืนผ้าใบจริงๆ แม้ว่าจะไม่ได้บันทึกไว้ล่วงหน้าก็ตาม

เมื่อรวมกัน พื้นที่เหล่านี้จะช่วยให้พาเล็ตมีวิวัฒนาการอย่างเป็นธรรมชาติ โดยสามารถเริ่มต้นจากชุดเม็ดสี รวบรวมส่วนผสมที่มีประโยชน์ระหว่างการทาสี และค่อยๆ กลายเป็นคำศัพท์เกี่ยวกับสีเฉพาะบุคคล

![add-pigment](/images/screens/add-pigment.jpg)


## องค์กรที่นำคุณค่า

Lumi จัดระเบียบสีจานสีโดยคำนึงถึงคุณค่า เพราะจิตรกรมักจะคิดในความสว่างและความมืดก่อนที่จะคิดในเฉดสี การจัดกลุ่มมิกซ์ตามบทบาทวรรณยุกต์ช่วยให้ค้นหาสีที่อยู่ทางด้านขวาของรูปภาพได้ง่ายขึ้น ไม่ใช่แค่สีที่มีชื่อที่ถูกต้องเท่านั้น

จานสียังสามารถให้ความรู้สึกถึงระยะห่างของโทนสีของตัวเองได้ ภาพประกอบที่มีคีย์สูง ภาพบุคคลที่มีคีย์ต่ำ และทิวทัศน์ที่ถูกปิดเสียงอาจได้รับประโยชน์จากการเน้นค่าที่แตกต่างกัน และชุดสีสามารถสะท้อนถึงโครงสร้างนั้นได้

## การไล่ระดับสีและการเปลี่ยนภาพ

จานสีสามารถรวมถึงการไล่ระดับสีที่ได้มาจากสีของตัวเอง การไล่ระดับสีเหล่านี้มีประโยชน์สำหรับการเปลี่ยนแบบนุ่มนวล แถบอ้างอิง การศึกษาแสง และการเคลื่อนไหวของสีที่คงอยู่ภายในเอกลักษณ์ของชุดสี

เนื่องจากการไล่ระดับสีอยู่ในพาเล็ต พวกมันจึงเสริมภาษาสีเดียวกันกับเม็ดสีและบันทึกการผสมไว้ แทนที่จะรู้สึกเหมือนเป็นการเพิ่มเติมที่ไม่เกี่ยวข้องกัน

![gradients](/images/screens/gradient-editor.jpg)

## ขั้นตอนการทำงานจิตรกรรม

Palette Editor เป็นสถานที่สำหรับสร้างและปรับปรุงระบบสี ในขณะที่มุมมองพาเล็ตที่สว่างกว่าจะรองรับการเข้าถึงที่รวดเร็วระหว่างการลงสี ช่วยให้การออกแบบพาเล็ตสีเข้มพร้อมใช้งานโดยไม่ต้องบังคับให้มันอยู่เบื้องหน้าทุกครั้งที่เลือกสี

โดยรวมแล้ว Palette Editor จะช่วยเปลี่ยนการเลือกสีให้เป็นแนวทางปฏิบัติที่สอดคล้องกัน: เลือกเม็ดสี สำรวจส่วนผสม รักษาผลลัพธ์ที่เป็นประโยชน์ และปล่อยให้พาเล็ตกลายเป็นส่วนหนึ่งของเสียงของอาร์ตเวิร์ค

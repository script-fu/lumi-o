Рідний формат файлу Lumi створено для багатошарових малюнків, які мають залишатися надійними, доступними для перевірки та відновленням з часом. Його розроблено відповідно до реалій ілюстративної роботи: багато шарів, великі полотна, вбудована інформація про колір, маски, ефекти та дані для відновлення.

Замість того, щоб розглядати проект як одну непрозору краплю, формат зберігає структуру ілюстрації видимою для програми. Це дозволяє Lumi більш інтелектуально зберігати, завантажувати та відновлювати великі зображення, зберігаючи при цьому організацію, від якої залежать художники.

## Відкрита структура проекту

У проекті Lumi частини ілюстрації зберігаються окремо: структура зображення, вміст шару, маски, колірні дані, метадані та інформація про відновлення мають чітку роль. Це робить формат легшим для міркування та кращим для тривалого доступу, ніж закритий, монолітний контейнер.

Метою є не лише збереження пікселів, а й збереження робочого стану ілюстрації. Шари залишаються шарами, маски залишаються масками, а файл продовжує відображати спосіб створення ілюстрації.

## Призначений для великих картин

Великі багатошарові зображення можуть швидко стати важкими. Формат Lumi підтримує робочі процеси, де не кожен фрагмент даних зображення потрібно завантажувати в пам’ять одночасно. Проекти можуть залишатися адаптивними, завантажуючи частини зображення, які дійсно потрібні для перегляду, редагування, компонування або експорту.

Цей підхід допомагає складним файлам відчувати себе керованими, особливо коли ілюстрація містить багато прихованих, архівних, експериментальних або згрупованих шарів.

## Збереження без порушення потоку

Формат файлу підтримує як звичайне збереження проекту, так і легкі знімки у стилі відновлення. Це дає художникам можливість часто захищати роботу, не перетворюючи кожну контрольну точку на повну копію всього зображення.

Оскільки інформація про відновлення належить до структури проекту, Lumi може зберігати корисну історію поруч із ілюстрацією, але при цьому дозволяє автоматичні безпечні збереження зберігатися окремо від робочого файлу.

## Обмін та експорт

Нативний формат призначений для поточної роботи Lumi, тоді як формати експорту використовуються для обміну зведеними результатами або результатами, орієнтованими на сумісність. Підтримка імпорту допомагає перенести існуючі ілюстрації в багатошарове середовище Lumi, а підтримка експорту дозволяє готовим творам залишати формат проекту, коли вони готові до публікації, доставки чи подальшої обробки.

Ця різниця зберігає робочий файл насиченим і доступним для редагування, а також дозволяє створювати кінцеві зображення у звичайних зовнішніх форматах.

## Довгострокова надійність

Коротше кажучи, формат `.lum` — це практичний контейнер для серйозної роботи з малюванням: досить відкритий, щоб перевірити, достатньо структурований, щоб відновити, і достатньо гнучкий, щоб економічно обробляти складні багатошарові зображення.

Palette Editor は、Lumi のパレットを完全なカラー環境にする場所です。パレットを構成する顔料、アーティストが残すことにしたミックス、描画中に使った色、パレットの探索を形作る明度構造がここに集まります。

Lumi のパレットはスウォッチの一覧以上のものです。作品全体や一連の制作を導ける、材料、覚えておきたい混色、明度関係、グラデーションから成る実用的なカラーシステムです。

![palette-editor](/images/screens/palette-editor.jpg)

## 芸術的な制約としてのパレット

多くの画家は、限られた馴染みの色のセットの中で最も力を発揮します。小さな顔料セットは統一感を生み、雰囲気を決め、すべての混色が同じ視覚的ファミリーに属するため、色の判断も速くなります。

Palette Editor は、そのような意図的な制限と、より広いフルスペクトルパレットの両方を支えます。主題、プロジェクト、スタイル、照明条件ごとに別パレットを持て、それぞれに独自の個性と混色の挙動を持たせられます。


![palette-editor-zorn](/images/screens/palette-editor-zorn.jpg)


## 顔料、ミックス、記憶

パレット顔料が土台になります。システムの残りが育つ色を定義し、Lumi の他のカラーツールで生成されるミックスにも影響します。

保存したミックスは、残して名前を付け、戻って使いたい色という意図的な発見を表します。使用色はもう一段静かな記憶で、事前に保存していなくても、実際にキャンバスに載った色を残します。

これらが合わさることで、パレットは自然に育ちます。顔料セットから始まり、描画中に有用な混色を集め、やがて個人的な色の語彙へとなります。

![add-pigment](/images/screens/add-pigment.jpg)

## ユーザー顔料

画家はよく色の山をあらかじめ混ぜます。中性色で抑えたマーズレッド、落ち着かせた黄、暖かい影などです。それらを絵の作業用の原色として扱います。保存したミックスはその発見を残せますが、ミックスはまだ顔料ではありません。パレットの残りを生成せず、別のパレットに顔料として追加できません。

保存したミックスはユーザー顔料に昇格できます。すると通常のパレット顔料と同じように振る舞います。ミックスを生成し、マップに現れ、他の顔料と同じように選べ、昇格元のミックスの色を保ちます。同じ顔料は共有ライブラリからどのパレットにも追加できます。

そのライブラリはリンクされたままです。ユーザー顔料の名前変更、置き換え、削除は、それを使うすべてのパレットに届きます。作業用の原色は1つのファイルに閉じ込められず、アーティストの色の語彙とともに育てられます。

## 明度を軸にした整理

Lumi は画家が色相より先に明暗で考えることが多いため、明度を意識してパレット色を整理します。ミックスをトーンの役割ごとにグループ化すると、名前が合っている色だけでなく、絵の適切な部分に属する色も見つけやすくなります。

パレットは独自の明度間隔の感覚も持てます。ハイキーのイラスト、ローキーの肖像、くすんだ風景は、それぞれ異なる明度の強調から恩恵を受け、パレットがその構造を反映できます。

## グラデーションと遷移

パレットには、自身の色から派生したグラデーションを含められます。ソフトな遷移、参照ストリップ、照明の検討、パレットのアイデンティティ内に留まる色の動きに有用です。

グラデーションもパレットに属するため、無関係な追加物ではなく、顔料や保存ミックスと同じ色の言語を強めます。

![gradients](/images/screens/gradient-editor.jpg)

## 描画ワークフロー

Palette Editor はカラーシステムを構築・洗練する場所で、軽量なパレット表示は描画中の素早いアクセスを支えます。色を選ぶたびに深いパレット設計を前面に出す必要はありません。

全体として、Palette Editor は色選びを一貫した実践に変えるのを助けます。顔料を選び、混色を探し、有用な結果を残し、パレットを作品の声の一部にしていきます。

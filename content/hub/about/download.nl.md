Lumi is beschikbaar als kant-en-klare ontwikkelings-AppImage en als broncode in de openbare repository. De AppImage is de snelste manier om de software op Linux uit te proberen; de repository is de juiste plek als u de ontwikkeling van dichtbij wilt volgen, de code wilt bekijken of zelf wilt bouwen.

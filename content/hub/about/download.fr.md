Lumi est disponible sous forme d'AppImage de développement prête à l'emploi et de code source dans le dépôt public. L'AppImage est le moyen le plus rapide d'essayer le logiciel sous Linux ; le dépôt est l'endroit idéal si vous voulez suivre le dévelopnement de près, examiner le code ou le compiler vous-même.

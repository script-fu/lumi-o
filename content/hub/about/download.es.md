Lumi está disponible como AppImage de desarrollo lista para ejecutar y como código fuente en el repositorio público. AppImage es la forma más rápida de probar el software en Linux; el repositorio es el lugar adecuado si quiere seguir el desarrollo de cerca, inspeccionar el código o compilarlo usted mismo.

Lumi ist sowohl als betriebsbereites Entwicklungs-AppImage als auch als Quellcode im öffentlichen Repository verfügbar. Das AppImage ist der schnellste Weg, die Software unter Linux auszuprobieren; das Repository ist der richtige Ort, wenn Sie die Entwicklung genau verfolgen, den Code prüfen oder selbst bauen möchten.

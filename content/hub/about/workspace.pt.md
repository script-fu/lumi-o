Os espaços de trabalho são parte fundamental do Lumi, disponíveis directamente no menu Espaços de trabalho. Mudam de forma rápida e suave, pelo que passar de uma fase de um projecto para outra é como seleccionar um modo de aplicação.

O objectivo não é forçar todos os controlos, painéis e recursos num único espaço universal. Cada espaço de trabalho pode ser moldado para uma tarefa específica, com apenas as ferramentas, plug-ins, paletas e caminhos de recursos realmente necessários para essa fase. Se estiver a fazer um desenho de construção, por exemplo, uma única predefinição de ferramenta pode bastar, o arranque mantém-se rápido e a interface permanece simples porque foi construída para essa tarefa e não para todas as possíveis.

O Lumi inclui três espaços de trabalho principais de fluxo: Construção, Encreagem e Cor. Estes são os principais espaços de produção. Inclui também vários layouts alternativos e temáticos para que os utilizadores vejam a flexibilidade do sistema de espaços de trabalho, experimentem disposições diferentes e adaptem o software à forma como preferem trabalhar.

O Lumi está disponível como AppImage de desenvolvimento pronta a usar e como código-fonte no repositório público. A AppImage é a forma mais rápida de experimentar o software no Linux; o repositório é o sítio indicado se quiser acompanhar o desenvolvimento de perto, examinar o código ou compilá-lo.

O Lumi está disponível como AppImage de desenvolvimento pronto para uso e como código-fonte no repositório público. O AppImage é a forma mais rápida de experimentar o software no Linux; o repositório é o lugar certo se você quiser acompanhar o desenvolvimento de perto, inspecionar o código ou compilá-lo você mesmo.
